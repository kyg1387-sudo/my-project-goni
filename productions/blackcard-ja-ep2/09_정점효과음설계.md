# 『ブラックカード』(第2話) 긴장 정적(BGM 0) + 효과음 설계 (2026-11-05, 고니감독님 검토 요청 「긴장감 있는 장면은 BGM을 끄고 효과음으로 몰입감」)

근거 규칙: 최우선 원칙 6④(정점 전 1~2초 저역 드론·심장 박동 → 정점은 정적 + 전용 효과음), 제19장 14(긴박한 순간은 BGM 0, 효과음 +2~4 dB, 룸톤 유지), 제19장 26(정점 효과음은 전용 생성·피크 기준), 제20장 10②(Lock 단계 PAUSE로 정적 확보, 콜백은 같은 파일).
타임코드는 대본 v1.4 추정값이고, PHASE 1 Lock 뒤 `lock.json` 기준으로 다시 적는다.

## 검토 결론

**가능하고, 2화에 맞는 방식이다.** 2화는 서고·전화·녹음·최상층처럼 「소리로 무서운」 장면이 1화보다 많아서, BGM을 빼면 현장 소리가 곧 공포가 된다. 다만 그대로 넣으면 아래 4가지 이탈 위험이 생기므로 규칙을 함께 건다.

| 위험 | 원인 | 대책 |
|---|---|---|
| ① 「소리가 끊겼다」로 느낀 시청자 이탈 | BGM 0 + 대사 없음 + 정지 화면이 겹치면 휴대폰에서 고장처럼 보인다 | 정적 안에서 **1.5초마다 소리 사건 1개**(초침·숨·LED 틱·얼음), 룸톤 −52 dBFS 유지, 베드 −30 dBFS 아래 금지(최우선 원칙 6①). 정적 창은 최대 2.0초 |
| ② 반복 패턴 피로 | BGM 0이 1분마다 오면 「또 조용해진다」가 예측된다 | **완전 정적(정점) 5곳 + 현장음 장면(전화·녹음) 4곳**으로 성격을 나누고, 정점끼리는 60초 이상 띄운다. T7(鷺沼)은 완전 0이 아니라 덕킹 −10 dB로 낮추고, 0은 L314 뒤 1.5초만 둔다(바로 뒤 T8 최상층 28초 BGM 0과 붙지 않게) |
| ③ 휴대폰 스피커에서 안 들림 | 드론·심장 박동은 100 Hz 아래라 휴대폰 스피커로는 재생되지 않는다 | 심장 박동은 어택(200~400 Hz 성분)이 있는 음원을 고르고, 드론에 2배음 레이어를 얹는다. 검수 때 **휴대폰 시뮬레이션 렌더**(HPF 200 Hz + LPF 8 kHz)로 정점 9곳이 들리는지 확인한다 |
| ④ BGM 재진입이 뜬금없음 | 대사 중간에 음악이 들어오면 정점이 흐려진다 | 재진입은 항상 **임팩트·도장·서명 같은 「터짐」 프레임**이나 내레이션 첫 음절 0.5초 앞(J컷)에 둔다. 대사 중간 재진입은 금지한다 |
