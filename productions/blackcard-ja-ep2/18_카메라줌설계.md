# 『ブラックカード』(第2話) 카메라 앵글·줌 긴장 설계 (2026-11-05, 고니감독님 검토 요청 「카메라 각도와 줌으로도 긴장감과 몰입감」)

근거 규칙
- 제8장 2·3·4·4-1·4-3: 앵글의 의미, 왜곡 상한, 안정도 축, 권력 역전
- 제8장 6: 한 컷 한 무빙, 편집 구현
- 제19장 17: 점프 컷 1.10 / 펀치 6회 이하 1.12배 / 슬로우 줌 초당 1.5% 이하 / 움직이는 컷 35% 이하·연속 3컷 금지
- 최우선 원칙 6②: 5초 넘는 한 구도는 두 번째 카메라 동작으로 깬다

컷 ID는 PHASE 3 생성기에서 정해지므로 지금은 줄(L) 기준으로 적는다. 모두 `finalize_*.py` 로컬 편집이라 비용은 0이다(돌리줌의 2.5D 마스크 포함).

## 검토 결론

**가능하다. 그리고 효과음 설계(09)와 한 몸으로 움직여야 효과가 난다.** 원칙은 「소리가 비면 카메라가 일하고, 터지는 프레임은 소리와 카메라가 같이 친다」다.
- BGM 0 정적 동안은 카메라가 아주 천천히 다가가(1.00→1.05) 숨을 조인다.
- 정점 프레임은 효과음과 **같은 프레임**에 펀치 인한다.
- 정점 직후에는 와이드·풀백으로 숨을 놓아준다.

일본 감동·スカッと 장르는 예능식 줌 남발을 싫어한다(제14장 3). 그래서 **확대는 1.12배 상한, 펀치 인은 6회 전부를 정점 6곳에만** 쓴다.

## 3. 긴 BGM 0 구간의 화면 리듬(5초 규칙 + 연속 3컷 금지)

- **T3 声 통화(약 60초)**: 「켄지 3/4(고정) → 감시카메라 시점(정지 + 그레인 흔들림) → 렌즈 ECU(정지) → 켄지 눈 CU(슬로 인) → 먹칠 인서트(랙 포커스) → 켄지 옆얼굴 i2v(숨)」. 움직임 있는 컷과 고정 컷을 번갈아 두고, 한 구도는 5초 이내로 한다.
- **T8 최상층(약 28초)**: 「엘리베이터 패널 ECU(고정, 램프만 변함) → 켄지 옆얼굴(고정) → 문 로우앵글(고정 → 문만 열림) → 방 와이드(슬로 인) → 액자 패닝 → 돌리줌 → 커피 김(i2v, 고정)」. 고정 컷에도 김·램프·항공장애등 같은 **화면 안 움직임**을 둬서 「멈춘 화면」으로 보이지 않게 한다.
- 움직이는 컷 비율은 생성기에서 집계한다(전체 35% 이하, 연속 3컷 금지 자동 경고).
