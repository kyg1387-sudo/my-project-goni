## 1. 영화 전체 앵글 규칙 (모든 컷에 적용)

| # | 규칙 | 기준 |
|---|---|---|

| A2 | **180° 축 고정** | 대화 장면은 두 인물을 잇는 가상선 한쪽에서만 촬영. 축을 넘을 때는 인서트·중립 컷(정면/수직)을 한 컷 거친다 |

| A6 | **렌즈 4단** | 24mm 와이드(공간·위압) / 35mm 상황 / 50mm 대화 미디엄 / 85mm 감정 CU, 인서트는 100mm 매크로 |

## 2. AI 제작에서 지켜야 할 앵글 한계 (김씨 시리즈 실증)

| 한계 | 대응 |
|---|---|
| OmniHuman 대사 CU는 **정면~45°**까지만 안정 (측면 대사는 입이 뭉개짐) | 대사 CU는 정면 또는 3/4. 측면·뒷모습은 입 안 보이는 대사 처리에만 |
| 롱샷은 얼굴 동일성이 약함 (EP3 S26) | 와이드에서는 얼굴을 작게(실루엣·뒷모습). 얼굴로 누구인지 알아봐야 하는 컷은 미디엄 이상 |
| i2v 고개 회전 20° 초과 시 얼굴 변형 | 「돌아보는」 동작은 컷을 나눠 앞 컷 끝 / 다음 컷 시작으로 처리 |
| i2v는 줌·초점 이동·카메라 회전 지시를 무시 | 푸시인·풀백·돌리줌·랙 포커스·더치·핸드헬드는 **편집에서 로컬로** (무료) |
| 장소 시트에 없는 시점은 배경이 어긋남 | 주 무대(편의점 안팎)는 **앵글 시트를 추가**해 역방향·하이·로우 시점을 미리 잠근다 (아래 4장) |

## 4. 앵글 다양화를 위한 시트 추가 (PHASE 2 반영)

주 무대인 편의점 안팎이 전체 컷의 약 60%다. 2x2 시트 하나로는 역방향·하이·로우 시점 배경이 어긋나므로 **앵글 시트 2장을 추가**한다. 장당 약 0.04달러.

| 시트 | 4칸 구성 |
|---|---|
| `loc-store-int-angles` | 입구에서 카운터 쪽 역방향 / 천장 모서리 CCTV 하이앵글 / 바닥 높이 로우앵글(반짝이는 바닥) / 진열대 사이로 본 창고 문 |
| `loc-store-ext-angles` | 아스팔트 높이 로우앵글 / 길 건너편에서 본 정면 / 버들가지 너머 유리문 / 블루아워 길 건너 시점 |

같이 반영하는 조명 변경(조명·카메라 가이드 분석):
- 사무실 시트 → 위에서 내리꽂는 차가운 형광등(5600K 이상)
- 우물·병실 시트 → 골든아워 셀
- 편의점 내부 → 점검일 입구 역광 셀

**PHASE 2 1차 합계: 13장 → 15장, 약 0.60달러.**

## 4-1. 앵글 분포 검토 (v1 → v2, 2026-10-04)

제8장 7(한 앵글 60% 초과 시 재설계) 자체 점검에서 v1이 아이레벨 66%(정면 45 + 측면·뒷모습 21 / 99컷)로 기준을 넘어 v2에서 14컷의 앵글을 바꿨다. 집계는 `03_앵글분포.md`. 사이즈·렌즈 표기가 빠진 컷은 PHASE 3 생성기에서 **필수 입력**으로 강제한다(빈 값이면 빌드 중단).

## 5. 확인 방법

- **PHASE 3:** 생성기가 A1(연속 같은 구도)과 A2(축 위반)를 자동 검사해서, 위반하면 빌드를 멈춘다.
- **PHASE 4:** 키프레임 검수 시트에서 장면별 앵글 분포(EL/HA/LA/OH 비율)를 함께 보고한다.
