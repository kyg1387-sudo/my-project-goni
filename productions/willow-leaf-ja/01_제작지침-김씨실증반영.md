**운영 규칙**
- burn이 실행 중일 때는 브랜치에 푸시하지 않는다.
- 실패한 run은 `resume_run_id` 또는 `deliver_from_run_id` + `commit_output=true`로 무료 회수한다. Artifact는 7일 뒤 사라진다.
- 수정 요청은 번호 목록으로 관리하고, 「보류」 항목이 하나라도 남아 있으면 전달하지 않는다.

## 3. 코드 수정 목록 (전부 무료, 생성 전에 끝낸다)

### P0 — 고치지 않으면 이 작품에서 반드시 오류가 난다

| # | 문제 | 수정 |
|---|---|---|
| C1 | 장면이 100개를 넘으면 `scene100`이 `scene10` 바로 뒤에 정렬돼 **조립 순서가 깨진다**. 대상: `concat_scenes`, `rebuild_with_lipsync`, burn의 `ls\|sort` | 파일명을 `scene%03d`로 통일하고 자연 정렬을 쓴다. 워크플로 printf와 override 파일명도 같이 바꾼다 |
| C2 | BGM 구간 파일 `bgm01..NN.audio`가 Artifact에 올라가지 않는다. 그래서 remix·resume 때마다 **Lyria를 다시 과금하고 승인된 곡이 바뀐다** | burn 업로드 경로에 `out/audio/bgm*.audio` 추가 |
| C3 | burn과 `qa-language.yml`의 언어 검사가 `--lang`을 넘기지 않아 일본어 전 줄이 오탐 처리된다 | `qa_lang`·`qa_model` 입력을 추가하고 기본값을 ja / large-v3로 |
| C4 | `build_ep4_keyframes`의 `people` 집합과 `WHO`가 EP4 배역으로 고정돼 있다. 그대로 쓰면 인물 컷에 「무인」 지시가 들어가거나 KeyError가 난다 | yanagi 배역 키로 교체하고, 빈 집합이면 SystemExit |
| C5 | `build_ep4_phase3`에 EP4 숫자가 박혀 있다 (`assert ==54`, `range(1,35)`, S52 특례, ref_map, MiniMax 폴백 목소리) | 상수를 데이터에서 계산. override가 빠진 줄은 **유료 폴백 대신 SystemExit** |
| C6 | burn의 `source_run_id` 기본값이 붕어빵 run이다 | 기본값을 비우고 필수 입력으로 |

### P1 — 비용 낭비를 막는 안전장치

| # | 문제 | 수정 |
|---|---|---|
| C7 | 키프레임도 override도 없는 장면이 **유료 t2v로 넘어간다** | generate 전에 「react/still/reuse 장면은 override 필수」를 검사하고 없으면 중단 |
| C8 | OmniHuman 8초 이하 규칙을 검사하는 코드가 없고, 무음 꼬리까지 과금된다 | 생성기에서 대사 장면 길이가 8초를 넘으면 오류. 세그먼트를 「대사 앞 0.3초 ~ 대사 끝 0.5초」로 자른다 |
| C9 | `voice_audition`의 Typecast 기본 언어가 `kor`이다 | 테스트마다 `jpn`을 명시하고, 빠지면 오류 |
| C10 | 폴링 루프에 타임아웃이 없다 | 20분 타임아웃과 상태 로그 |
| C11 | `video-overrides` 폴더가 비어 있으면 `cp`가 실패한다 | glob 가드 |
| C12 | `ipag.ttf`가 워크플로에 설치되지 않는다 | `fonts-ipafont-gothic` 설치 단계 추가 |

### 쓰지 않는 것

- **`retime_transitions.py`**: 생성기의 Lock 타임라인과 함께 쓰면 이중으로 압축된다.
- **`add_audio=true` + `lipsync=false`**: 타임라인이 어긋난다. `lipsync=true` 또는 `remix`만 쓴다.
