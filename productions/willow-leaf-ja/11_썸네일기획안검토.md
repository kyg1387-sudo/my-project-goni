## 결론

**구도·색·글자 디자인은 그대로 적용 가능. 문구·제목·이미지 생성 방식은 수정이 필요하다.**

| 항목 | 판정 | 이유 |
|---|---|---|
| 3분할 대비 구도(점장 40% / 회장 40% / 가운데 유나) | ✅ 적용 | 승인된 키프레임 S14g(점장 협박 CU)·S27g(회장 판결 CU)·S14d2(유나의 떨리는 손)로 바로 구성. 인물 얼굴이 본편과 같다 |
| 점장 푸른 톤 + 붉은 역광, 회장 금빛·무거운 그늘 | ✅ 적용 | 편집에서 색 처리(시안 A) |
| 오른쪽 아래 비우기(재생 시간 표시) | ✅ 적용 | 시안 A·B 모두 비움 |

| 2열 문구 「調子に乗った店長の末路」 | ⚠ 수정 권장 | 11자로 길다(시리즈 규칙 1줄 8자 이내, 휴대폰에서 0.3초 판독). 극 중 직함은 「店長代理」 → **「店長代理の末路」**(7자) |
| 폰트 Meiryo | ⚠ 교체 | Windows 동봉 글꼴이라 상업 이미지 사용 허락이 불분명. 같은 느낌의 **Zen Maru Gothic Black**(오픈 라이선스, 저장소에 있음)으로 대체 |
| 이미지 AI 프롬프트(anime/webtoon, Midjourney) | ❌ 쓰지 않음 | ① 본편은 실사풍 — 썸네일만 만화풍이면 제목의 【漫画】와 함께 「만화 영상」으로 오해(클릭 후 이탈) ② 새로 생성하면 점장·회장 얼굴이 본편과 달라진다(규격 PHASE 2 인물 고정) ③ `--v 6.1 --stylize`는 Midjourney 전용이라 fal에서는 무시된다. 승인 키프레임 합성이면 **비용 0원** |
| 회장 「팔짱 끼고 서늘하게 내려다보는」 표정 | ⚠ 선택 | 지금 키프레임(S27g)은 차분하고 단단한 표정. 내려다보는 표정이 꼭 필요하면 S27g를 같은 얼굴로 편집 1장(약 $0.04) |

| 제목 「サインを強要」 | ⚠ 수정 | 극 중은 서명이 아니라 시말서와 도장(ハンコ) |
| 제목 「バイトの正体が“会長の恩人”」 | ❌ 수정 | 정체가 숨겨진 인물은 알바생이 아니라 **쫓겨난 노인(=회장)**. 60년 전 회장의 은인은 유나의 할머니. 결말과 어긋난다 |
| 대체 제목 「文句があるなら辞めろ」 | ❌ 수정 | 대본에 없는 대사 |

## 이 작품의 가장 강한 후크(기획안에서 빠진 것)

일본 시니어 「スカッと·感動」 장르에서 가장 잘 먹히는 반전은 **「쫓아낸 초라한 노인이 사실 본사 회장」**이다(대본 0:20~1:30, 9:41 본편 전체의 축).
기획안은 회장을 처음부터 정장 차림 「흑막」으로 보여 줘 이 반전을 쓰지 못한다. 그래서 시안 B를 함께 만들었다.

## 시안

| 시안 | 화면 | 문구 |
|---|---|---|
| **A 기획안 적용** | 왼쪽 점장(푸른 톤·붉은 역광) / 가운데 유나의 떨리는 손 / 오른쪽 회장(금빛) | 「黙ってハンコ、押しなよ」 + 店長代理の**末路** |
| **B 반전형** | 왼쪽 땀 흘리며 애원하는 노인 / 오른쪽 같은 얼굴의 정장 회장 | 追い出した老人は… + [三日後] + **会長**だった |

## 제목 × 썸네일 조합 (썸네일이 질문, 제목은 답을 숨김)

| 순위 | 썸네일 | 제목 |
|---|---|---|
| 1 | B 반전형 | 「水を一杯だけ…」倒れた老人を追い出した店長代理。三日後、本部から来た“ある人”を見て顔面蒼白に…【スカッと・感動】 |
| 2 | A 기획안 적용 | 祖母の入院費を盾に「黙ってハンコ押しなよ」…バイトを脅した店長代理が、三日後に土下座した理由【スカッとする話】 |
| 3 | 기존 업로드 가이드 ① (유나 눈물) | 老人を追い出した店長代理、三日後に土下座した理由…一杯の水と柳の葉が繋いだ六十年の奇跡【感動】 |

- 업로드 때 세 썸네일을 「테스트 및 비교」에 함께 등록하고 2주 뒤 시청 시간 점유율로 확정.
- 「実話」(실화) 표현 금지, 설명란 마지막 「この物語はフィクションです」 유지, AI 합성 콘텐츠 공개 「예」.
- 썸네일에 피·폭력·수갑 없음(광고 제한 방지) — 두 시안 모두 해당 없음.
