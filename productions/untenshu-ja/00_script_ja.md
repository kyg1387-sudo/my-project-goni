## 4-3. 갈등 심화 × 사이다 폭발 증폭 설계 — 고니감독님 지시 (2026-10-13 v1.1 승인 시)

> 「단순 시간 채우기가 아니라 갈등 심화와 사이다의 폭발력이라는 스토리텔링의 핵심 동력을 최대로」. 보강 11줄을 아래 장치에 묶어 **분노를 계단식으로 쌓고 → 한 번에 터뜨린다**. PHASE 3 생성기·마무리 편집·사운드의 검사 항목으로 이어진다.

**A. 갈등 심화 — 분노의 계단 (시청자 분노 게이지를 한 칸씩 올림)**

**B. 사이다 폭발 — 3단 점화**

1. **정체 발각(S17)**: 역광 실루엣 → 돌리줌(작품 1회) → 저음 히트 1회 → L34 「……昨夜は、どうも」 뒤 1.0초 완전 정적. 명함 쥔 손 떨림 ECU.
2. **증거(S18)**: 회의실 정적 속 태블릿 스피커로 L11·L14 고함 재생(전화 스피커 필터) → 0.8초 빠른 3단 컷(石井 안경 벗음 → 大塚 땀 ECU → 小川 숨 멈춤). 「運転手のくせに」가 **작품 안에서 네 번째**로 울릴 때, 이번엔 大塚 자신을 찌른다.
3. **판결(S19~S20)**: P9 石井의 수습 시도 → **P10 「処分の、問題ではないんです」**로 탈출구 차단 → L41 무릎(버즈아이 + 더치 7° 붕괴) → L42 黒田가 「“運転手のくせに”」를 **되돌려줌**(로우앵글, 0.6초 정적) → L43·L44 결정타. BGM은 L44까지 차갑게, **L45(小川 언급)에서 따뜻한 현악으로 반전**.

**C. 여운의 응징과 보상 — 수미상관 대비 컷**

- **P11**: S04에서 손을 들던 그 번화가, 같은 구도·같은 네온 — 빗속에서 손을 드는 大塚를 빈 택시 불빛들이 지나친다(하이앵글, 무력).
- **바로 다음 S23**: 같은 비, 小川가 손을 들자 黒田의 택시가 멈춘다(아이레벨, 따뜻한 앰버). 두 장면을 같은 화면 구도로 맞춘 매치 컷 = 이 작품의 결론을 그림으로.
- 상징 액자 6회: S02 소개 → S07 추락 → S10 小川가 닦음 → S13 흠집(P4) → S21 黒田의 언급 때 흠집 인서트 재등장 → S23 대시보드 제자리.

**D. 쇼츠 4편 갈래 (미리 지정)**: ① L11 폭언(후크) ② P2 「しつけてやったよ」 → P8 → 문 열리기 직전 끊기(반전 직전) ③ S18~S20 레코더 → 「その“運転手”ですよ」(사이다) ④ P11 → S23 대비(결말 한 컷).
