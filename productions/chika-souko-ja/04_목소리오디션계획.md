## 2. 발견한 제약 — Typecast에 일본인 중장년 남성 목소리가 없음

Typecast 목록(608개)에서 일본인 원어민 이름의 남성 목소리:

| 연령대 | 원어민 남성 | 비고 |
|---|---|---|
| 노년 | **Hideo Watanabe 1명뿐** | 미야모토용 새 원어민 노인 목소리가 Typecast 안에는 없음 |
| 중년 | **0명** | 곤도(52)·기리타니(50대)·오코치(60대)에 맞는 원어민 목소리 없음 |
| 청년 | Daichi Inoue · Kenta Yoshida · Takuya Murakami · Ryouta Takahashi(#01 담당자) · Touma Murata(#01 주민) | 중년 배역은 저음 처리(tonedown·느린 속도)로 연령감을 내야 함 |

#01에서도 비원어민 노년 목소리 Poseidon을 썼다가 「일본어 자연스럽게」 요청으로 Hideo로 교체한 이력이 있음 → 비원어민 목소리는 1순위 후보에서 제외.

**결론**: Typecast만으로는 「새 원어민 노인 + 원어민 중년 3명」을 채울 수 없음 → **ElevenLabs 일본어 원어민 목소리 도서관**을 후보 풀에 추가해야 함.
- 걸림돌: #01 때 ElevenLabs 키에 `voices_read` 권한이 없어 도서관 검색이 401로 실패.
- 해결: 사용자가 ElevenLabs 설정에서 API 키 권한 「Voices: Read」를 켜기만 하면 됨(무료, 1분). 키 값은 바꿀 필요 없음.
- 목록 스냅샷 이후 Typecast에 새 목소리가 추가됐을 수 있어 오디션 전 목록을 다시 조회함(무료).

## 5. 합격 기준 (#01 방식)
1. Whisper large-v3 언어 검사: 일본어 판정 + 원문 일치(오독 시 가나 교정 후 재녹음)
2. **4명 구분**: 평균 음높이를 측정해 서로 2반음 이상 차이 + 블라인드 청취에서 섞이지 않을 것
3. 곤도 감정 폭: 비웃음과 절규 사이 억양 폭 측정(#01 레이카 기준과 비교)
4. 사용자 청취로 최종 확정 — 배역별 비교 파일(대본 순서) 전달

## 6. 비용
- Typecast 목록 재조회·Whisper 검사: 무료
- 오디션 생성: 배역 4명 × 후보 3명 × 3줄 ≈ 36샘플, 약 2,000자 → Typecast 크레딧 + ElevenLabs 크레딧 소량
  (앞서 안내한 약 1,000자에서 늘어남: 미야모토 추가 + 후보 3명 기준)
- 생성 실행 전 최종 후보 목록과 글자 수를 다시 보고
