# 『月に帰った契約社員』 카메라 앵글·대화 연출 설계 (v0.2 초안)

> 고니감독님 지시(2026-10-15): 「영화 촬영처럼 자연스럽게 다양하게 보여 줘야 하고, 서로 대화하는 게 자연스럽게」.
> 근거 규격: CLAUDE.md 제8장(앵글 다양화·의미·안정도 축), 제10장(일하면서 나누는 대화, 숏-리버스숏, L컷, 톤·표정·동작 일치), 제11장 12(B안 순서).
> 이 표는 PHASE 3 생성기(`build_tsuki_phase3.py`, ashita 생성기 복사)의 입력이 된다. 생성기가 「연속 같은 구도·180° 축 위반·더치 2회 초과·OMNI 45° 초과」를 자동 검사한다(제8장 7).

## 0. 이 작품의 「영화처럼」 공통 규칙

| 규칙 | 적용 |
|---|---|
| **장면 진입 공식** | 장소 설정 와이드(무인 또는 뒷모습) → 미디엄(일하는 손) → 어깨 너머 3/4 대사 → 리액션 CU → 인서트(소품) → 여운 와이드. 한 장면에 **사이즈 4종 이상** |
| **연속 컷 금지** | 같은 사이즈·같은 각도 연속 금지(사이즈 2단계 또는 30° 이상 변화). 생성기 자동 검사 |
| **전경 너머 컷** | 장면마다 1개 이상(유리벽·대나무·모니터·찻잔 너머) |
| **렌즈** | 24mm 설정 와이드 / 35mm 미디엄 / 50mm 어깨 너머 / 85mm 리액션 CU / 100mm 매크로 인서트(인감·주먹밥·竹とんぼ·금테 안경) |
| **앵글의 의미** | 鷲尾 전반 로우앵글(권력) → 후반 하이앵글·버즈아이(몰락). 光은 아이레벨(공감), 유일한 로우앵글은 S21 대나무 숲(존엄). 日野는 늘 약간 하이앵글(무력) |
| **카메라 안정도** | 光·さくら·篠田·할머니 = 고정·슬로우 푸시인만. 鷲尾·日野 = 압박·패닉 구간 미세 핸드헬드. 더치 5° S13(위조) · 7° S19(주저앉음), 돌리줌 S18 日野 「止まる」 1회 |
| **한 컷 한 무빙** | 푸시인·팬·틸트·핸드헬드 중 하나만. 전부 편집(로컬)에서 구현 |

## 1. 「서로 대화하듯」 공통 규칙 (제10장 8 확장)

| 규칙 | 적용 |
|---|---|
| **숏-리버스숏 180° 축** | 두 사람 장면은 축을 한 번 정하고 장면 끝까지 유지(A 전경 왼쪽·시선 오른쪽 ↔ B 전경 오른쪽·시선 왼쪽). 아래 표에 장면마다 축 표기 |
| **듣는 사람을 반드시 보여 준다** | 대사 2줄마다 최소 1컷 듣는 사람 리액션(i2v: 눈 깜빡임·숨·손 멈춤·고개 끄덕임·시선 피함). 리액션 컷은 **방금 들은 말에 대한 반응**을 동작 문장에 쓴다(예: 「L26 고함을 듣고 어깨가 움츠러들지만 시선은 피하지 않는다」) |
| **L컷·J컷** | 4.5초 넘는 대사는 말 끝 1.0~1.5초 듣는 사람으로(L컷). 대사 시작 0.5초 전 상대 얼굴에서 목소리가 먼저 들어온다(J컷) — 장면당 1회 이상 |
| **말 겹침(かぶせ)** | 감정이 터지는 곳만 0.2초 겹침: S19 L43→L44(책임 전가). 나머지는 같은 화자 0.6초·화자 교체 0.8초 |
| **말하면서 일한다** | 화자의 손은 늘 무언가를 한다(걸레·수건·펜·찻잔·손수건·대나무·봉지). 정면 응시 금지, 상대를 3/4로 본다 |
| **말 중간의 작은 멈춤** | 대본의 「……」는 음성에서 0.3~0.5초 실제 멈춤 + 키프레임은 시선 이동(아래→상대) |
| **듣는 사람의 몸** | 받아들일 때 고개 끄덕임, 거부할 때 시선 피함·손 멈춤, 충격 때 숨 멈춤(가슴 정지) — i2v 동작 문장에 명시 |
| **립싱크 연기 지시** | `OMNI_ACT`에 「누구에게, 무엇에 대답하는지 + 감정 + 강조 낱말」(예: L29 「鷲尾의 눈을 보며 차분히, 「十二条」를 또박또박」) |
