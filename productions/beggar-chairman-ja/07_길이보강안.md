## ③ 전개·위기 +60초 — 영상 확산(긴장) + 「합図」 회수

```
S10-2 (L27a 뒤) 間宮가 휴대폰 화면을 친구들에게 보여 준다. 화면 [합성]: 「物乞いジジイ、高級店で門前払いｗ」 업로드 · 「いいね」 숫자가 올라간다.
   L27b 間宮 [Omni] (휴대폰을 흔들며 웃음):「もう再生、千回超えたわ。じいさん、有名人じゃん」
   → 벌써 조회수 천 회 넘었네. 영감님, 유명인이네.
   L27c ちひろ [Omni] (間宮 쪽으로 돌아서며, 떨리는 목소리로):「やめてください。人を笑いものにするなんて……」
   → 그만하세요. 사람을 웃음거리로 만들다니……
   L27d 間宮 [VO] (어깨를 으쓱):「バイトが、客に説教？」
   → 알바가 손님한테 설교?

S11-2 (L30 뒤, NA14 앞) 노인이 낡은 휴대폰을 꺼내 버튼 하나를 누른다 — 손 인서트(화면은 어둡게).
   → 호텔 앞 세단 안, 榊의 휴대폰이 한 번 진동한다 [i2v]. 榊이 화면을 보고 조용히 문을 연다.
   L30a 榊 [Omni] (운전기사에게, 낮게):「……合図です。行ってきます」
   → ……신호입니다. 다녀오겠습니다.
   (호텔 로비를 가로지르는 榊의 구두 — 로우 인서트 [i2v])
   L30b 岩城 [Omni] (아무것도 모른 채 노인을 내려다보며):「今さら、何をしても無駄ですよ。警備を呼びますから」
   → 이제 와서 뭘 해도 소용없어요. 경비를 부를 테니까.
```

효과: NA9 「その男が待っていたのは、ある老人の、合図でした」를 직접 회수하고, 2차 광고 「誰も知らなかったのです……」 직전 긴장을 최대로 올린다.
