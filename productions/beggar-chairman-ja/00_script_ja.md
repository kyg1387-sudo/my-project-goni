## 1. 기획 요지

| 항목 | 내용 |
|---|---|
| 한 줄 | 낡은 점퍼 차림의 노인이 도쿄 鷹宮ホテル의 일식당 「鷹宮亭」에서 「物乞いは裏口から」 쫓겨난다. 노인은 그룹 창업자 鷹宮源蔵. 칠십 년 전 이 자리의 작은 우동집에서 공짜 かけうどん을 얻어먹던 고아였다. 남은 시간 1년, 회사를 물려주기 전에 「배고픈 사람에게 밥을 내주는 곳인지」 직접 확인하러 왔다 |
| 사이다 | 정체 공개 → 「規則を作ったのは、わしじゃ」 → 소리치지 않는 해고 「明日からは、もう来なくて結構です」 → 지배인 土下座 |
| 人情 | 아무것도 모른 채 차와 まかない 우동을 내준 아르바이트생 ゆい → 「知らなかったから、よかったんじゃよ」 → 장학생, 메뉴에 「かけうどん　お代は、お気持ちで」 |
| 주제 대비(명대사 짝) | 지배인 「存じ上げず……」 ↔ 회장 「知っておったら、しなかったということじゃな」 / ゆい 「何も知らなくて……」 ↔ 「知らなかったから、よかったんじゃよ」 — **몰랐기 때문에 드러나는 진짜 인격** |
| 시리즈 | 엔딩 「その一行が、一年後、彼の孫を配達員にする」 → 다음 이야기(『会長の最後の配達』 일본판) 예고 |
| 지침 반영 | 폭력·피 없음 · 가상 회사명 검색(아래) · 대사는 일하면서(쟁반·찻잔·장부·휴대폰) · 숏-리버스숏 180° 축 · 4.5초 넘는 대사 L컷 · 화면 글자는 전부 `[합성]` · 권력 역전 앵글(黒田 전반 로우 → 土下座 버즈아이, 榊 등장 돌리줌 1회) |
