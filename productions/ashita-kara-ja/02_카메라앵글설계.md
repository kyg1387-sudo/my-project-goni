## 1. 영화 전체 앵글 규칙

| # | 규칙 | 이 작품 적용 |
|---|---|---|
| A1 | 연속 두 컷 같은 구도 금지 | 사이즈 2단계 또는 각도 30° 이상 차이. OMNI CU가 이어지면 앵글(LA↔EL)을 바꾼다 |
| A2 | 180° 축 고정 | 회의실은 「창 쪽=야마모토·타나카 / 문 쪽=사토」 축, 제어실은 「콘솔=모리 / 문=다카하시」 축 |
| A3 | 와이드 → 미디엄 → CU, 정점 뒤 와이드·인서트로 여운 | 후크·폭발은 예외 |
| A4 | 앵글의 의미 | 하이 = 무력·감시 / 로우 = 권력·위압 / 아이레벨 = 공감 / 오버헤드 = 운명·전모 |
| A5 | 권력 반전 | 전반: 타나카 LA(S04·S05·S07·S12), 사토 HA(S05·S11). 후반: 사토 LA(S24·S26), 타나카 OH(S25·S26) — 같은 회사 사람들 사이에서 앵글만 뒤집힌다 |
| A6 | 렌즈 | 24mm 공간·위압 / 35mm 상황 / 50mm 대화 / 85mm 감정 CU / 100mm 매크로 인서트 |
| A7 | 전경 프레이밍 | 장면마다 1컷 이상 유리 칸막이·문틀·창·모니터 **너머** |
| A8 | 시각 환기 | 정지성 컷 5초 초과 금지 → 긴 내레이션(S21)은 인서트를 촘촘히 |
| A9 | 왜곡 기법 | 더치: S12 타나카 고함 5°(1회), S19 야마모토 얼어붙음 7°(2회). 돌리줌: S24 사토를 알아보는 타나카 CU(1회). 주인공 장면에 더치 없음 |
| A10 | 카메라 안정도 | 사토·모리·다카하시 = 고정·슬로우 푸시인 / 타나카·야마모토 = 갑질·축배·패닉 구간 미세 핸드헬드. 전부 편집에서 구현 |
| A11 | 소품의 인격화 | 도장·낡은 차단기·명함·안전모는 화면 70% 이상 ECU, 얕은 심도 |
| A12 | 권력 역전의 극단 | S25·S26 무릎 꿇은 타나카 = 버즈아이(OH), 사토 = LA |

**조명 (제8장 1항, 로케이션 시트에서 잠금)**: 설계실 밤 = 텅스텐 스탠드 3200K + 림라이트(정직) / 설계실 낮·회의실·제어실 = 위에서 떨어지는 차가운 형광등 5600K 이상(압박) / 임원실 축배 = 탁한 금빛 간접광(탐욕) / 정문 비 = 가로등 역광·빗줄기 / S24 등장 = 문밖 강한 역광 실루엣(대면) / 새 사무실·S28 = 디퓨즈 아침광 + 골든 림(해방). Chiaroscuro는 S11·S12·S24·S25에만.

## 2. AI 한계 대응 (실증)

- OMNI 대사 CU는 정면~45°, 가슴 위, 손 미포함. 측면·뒷모습은 입이 안 보이는 대사에만.
- 와이드 인물은 실루엣·뒷모습(얼굴 동일성 약함). 감사단·경찰 없음, 정장 실루엣은 얼굴 없음.
- i2v 고개 회전 20° 이하. 푸시인·풀백·크레인·돌리줌·랙 포커스·더치·핸드헬드는 편집에서.
- 화면 글자(모니터·명함·서류·주가)는 무지 생성 후 `ja_text_overlay.py` 합성.

## 4. 앵글 시트 추가 (PHASE 2 반영)

주 무대는 컷 60% 이상이 나오는 **설계실·회의실·제어실**이다. 로케이션 시트 4셀(낮 와이드·밤 와이드·핵심 포지션 2)에 더해 앵글 시트를 1장씩 잠근다: 역방향(문 쪽에서 본 시점) · 하이(천장 모서리) · 로우(바닥 높이) · 전경 너머(유리 칸막이·문틀·모니터).
