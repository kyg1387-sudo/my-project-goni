# 『タワマンのボスママ』 카메라 앵글 설계 (CLAUDE.md 제8장 7)

> `scripts/build_tower_phase3.py`의 샷 표에서 자동 생성. 자동 검사 통과: 연속 같은 구도 0 · 더치 2회(S06a 5°, S15a 7° — 악역만) · 돌리줌 1회(S16d 정체 발각 순간 레이카) · 립싱크 컷 정면~45° · 악역 근접 CU 없음 · 초커는 유미만.

## 앵글 설계 원칙 (이 작품)

- **권력 역전**: 레이카는 전반 로우앵글(S01a·S01b·S06b·S13b) → 몰락 후 하이앵글·극단 부감(S16d·S17b·S17d·S19d). 오다기리는 로우앵글(S16b·S16f·S17e).
- **유미**: 전반 하이앵글(무력, S01c·S06e) → 총회부터 아이레벨 정면(S05e·S13d) → 엔딩 S19c 아이레벨 미소. 카메라는 고정·슬로 푸시인만(주인공 안정도 축).
- **악역 불안**: S06a 더치 5°(모욕) · S15a 더치 7° + S15b 핸드헬드(폭발).
- **매치 컷**: S01d(엘리베이터 문이 레이카 앞에서 닫힘) ↔ S19f(화물 엘리베이터 문이 레이카 앞에서 닫힘).
- **소품 인격화(ECU 70%)**: 유미의 펜(S07a·S07c2) · 버건디 가방(S06c·S16i2) · 통장(S14n·S17-2a) · 봉투(S12-2a → S16e 회수).
