## 최적화 반영 요약

## 등장인물

- **강만석 회장** (78) — 한성그룹 창업주. 의사에게 남은 시간 1년을 들었다. 회사를 물려주기 전, 자기 회사가 아직 "배고픈 사람에게 밥을 내어 주는 곳"인지 직접 확인하려 허름한 차림으로 나선다.
  - 외형 고정: 마르고 각진 얼굴, 짧게 깎은 흰머리와 흰 수염, 깊은 주름, 무릎이 해진 회색 면바지, 소매가 닳은 낡은 회색 점퍼(무지), 해진 흰 운동화
- **백 지배인** (45) — 한성호텔 레스토랑 「한성관」 지배인. 손님 등급을 옷차림으로 매긴다.
  - 외형 고정: 갸름한 얼굴, 포마드로 넘긴 검은 머리, 검은 쓰리피스 정장, 은색 넥타이, 가슴에 무지 금속 명찰
- **차민준** (32) — 한성 협력업체 2세 "대표님". 휴대폰으로 남의 굴욕을 찍는 버릇.
  - 외형 고정: 둥근 얼굴, 옆을 짧게 친 갈색 머리, 무지 크림색 니트와 로고 없는 명품풍 코트, 손목에 굵은 은시계
- **한서윤** (23) — 「한성관」 아르바이트 서버, 대학생. 등록금을 벌고 있다.
  - 외형 고정: 계란형 얼굴, 낮게 묶은 검은 머리, 흰 셔츠에 검은 앞치마(무지)
- **정 실장** — 한성그룹 비서실장. 「회장님의 마지막 배달」 인물 그대로(기존 초상 재사용).

**장소 고정 문구**: 한성호텔 1층 레스토랑 「한성관」 — 따뜻한 조명의 고급 한식 레스토랑, 흰 식탁보, 짙은 원목 벽, 큰 통유리창, 간판·메뉴판은 아무 글자 없는 무지.

## 구성 메모

- **구조**: 콜드 오픈(모멸 절정 + 정체 선공개) → 「한 시간 전」 → 무시 3단 고조(입구 → 구석 자리 → 해고) → 중반 예고 카드 → 콜드 오픈 합류 → 정적·신분 공개 → 차분한 참교육 → 국밥 한 그릇 → 유언장 한 줄 → 전작 예고
- **떡밥 회수**
  - "국밥 되겠소?"(S#2) → 메뉴에 없음 → 서윤이 몰래 담음 → 육십 년 전 공짜 국밥 → 오늘부터 메뉴에 국밥
  - "돈은 있소"(S#2) → "그 국밥 값은, 내가 내겠소"(S#6) — 같은 사람이 같은 말을 하는데 무게가 달라짐
  - 콜드 오픈 카드 "무릎을 꿇게 됩니다" → S#8 지배인 무릎
  - 유언장 한 줄 → 「회장님의 마지막 배달」 에필로그의 그 문장과 일치
- **명대사**: "몰라봐서 미안하다… 알아봤으면, 안 그랬다는 말이구먼." — 손자 도윤의 대사("회장인 줄 알았으면 안 그랬을 거라는 거")의 원형. 두 편을 이어 본 시청자만 아는 연결 장치
- **사이다 핵심 대사**: "내일부터는, 나오지 않아도 됩니다." — 소리치지 않는 해고(일본 スカッと 공식)

- [x] 단음절 감탄사 없음, 숫자 전부 한글 표기(이십만 원·육십 년·열두 살·일흔여덟·일 년)
- [x] 인과 순서 — 반응 대사("…하.", "회, 회장님이라니요…?")는 모두 원인 뒤
- [x] 소품 연속성 — 국밥 그릇: 서윤이 담음(S#4) → 노인 앞(S#5·S#0/6) → 식은 그릇(S#9 완충) → 다시 데운 그릇(S#9). 민준 휴대폰: 듦(S#0) → 내림(S#7)
- [x] 글자 금지 — 간판·메뉴판·명찰·점퍼 전부 무지. 신분은 대사로만 공개(명함·서류 클로즈업 없음)
- [x] 2단계 동작 없음 — 잡아당긴다 / 숙인다 / 꿇는다 / 뜬다, 한 컷 한 동작
- [x] 감정 온도 급변 지점(S#8→S#9)에 무인 완충 컷(식은 국밥)
- [x] 내레이션은 무언 구간(S#0 정지, S#1, S#4 주방, S#10)에만
- [ ] 회장 대사 클로즈업은 "가슴 위, 손 미포함" 구도(교훈 ⑪) — 숟가락 장면과 대사 컷 분리 완료, 장면 프롬프트 작성 시 재확인
- [ ] 기준 초상 4종 신규(회장·지배인·민준·서윤) + 정 실장 기존 재사용 — 생성 단계

## 일본판 제목·썸네일 후보

- 제목 A: 【スカッと】みすぼらしい老人を裏口へ追い出した支配人。30分後、老人の正体を知り顔面蒼白に…【感動】【韓国ドラマ】
- 제목 B: 「汚い年寄りは裏口から出ていけ」と言われた老人の正体は、韓国財閥の創業者だった【スカッとする話】
- 썸네일 문구(폰트 합성): 「まさかの正体」 / 「顔面蒼白」 — 지배인 질린 얼굴 + 정 실장 90도 인사 실루엣
- 제목에 「乞食」는 쓰지 않음(차별어). 대사 자막에서는 악역 대사 맥락상 「物乞い」 허용
- 핵심 대사 번역 기준:
  - 「明日からは、もう来なくて結構です。」(내일부터는, 나오지 않아도 됩니다)
  - 「知らなかったから申し訳ない…知っていたら、しなかったということですな。」
  - 「その子が、わしじゃよ。」(그 아이가, 나요)
