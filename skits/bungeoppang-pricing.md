# 붕어빵 가격 콩트

> 짧은 코미디 스킷 대본. `/` 는 자막(쇼츠) 줄바꿈 구분 표시.

## 대본

```
고객: 붕어빵 / 얼마예요?
사장: 예쁜 언니는, / 오백 원,
사장: 못생긴 언니는, / 천 원입니다.
고객: 근데... / 가격이 왜 달라요?
사장: 내가 볼때는 / 이 동네는...
사장: 예쁜 언니밖에 / 없어요!
고객: 하하하 / 그럼 저는 오백 원이죠?
사장: 잠깐만요, / 다시 한번 볼게요.
고객: ...왜 / 다시 봐요?
사장: 너무 예뻐서 / 삼백 원.
고객: 하하하 / 아 진짜 못 말려!
사장: 내일 오면 / 공짜예요.
고객: 왜요?
사장: 내일은 / 더 예뻐질 거니까.
고객: 하하하하

사장: (카메라 보며) / 오늘 매출 삼백 원.
사장: ...근데 / 흑자.
```

## 구성 메모

- **설정**: 붕어빵 노점, 사장과 고객의 짧은 대화
- **핵심 개그**: "예쁜 언니 할인" — 가격이 내려갈수록 칭찬이 커지는 구조 (500원 → 300원 → 내일은 공짜)
- **마무리**: 카메라를 보며 던지는 반전 한 줄 — "매출 삼백 원... 근데 흑자"
- **등장인물**: 사장(능청스러운 장사꾼), 고객(웃음이 많은 손님)
