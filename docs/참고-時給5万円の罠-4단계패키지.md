# 『時給5万円の罠』 4단계 패키지 (고니감독님 지시어 [단계 1~4] 전부 적용)

대본 본문(단계 2-1·2-2 번역·정제)은 `docs/참고-時給5万円の罠-일본어대본.md`. 이 문서는 나머지 단계 1, 2-3, 3, 4를 담는다.
주의: 이 채널(美談ものがたり)의 美談·スカッと 드라마와 장르가 다르다(다큐 시뮬레이션·범죄 서스펜스). 제작한다면 별도 재생목록이나 별도 채널을 권한다. 시청층이 섞이면 추천 알고리즘이 누구에게 띄울지 헷갈린다.

## 단계 1. 기획·훅 설계

### 1-1. 클릭 트리거 3가지 (일본 시청자)

| # | 트리거 | 종류 | 근거 |
|---|---|---|---|
| 1 | **「闇バイト」 실재 공포** | 감정(불안) | 일본 각지 강도 사건의 실행범이 SNS 闇バイト로 모집됐다는 보도가 이어짐. 「내 아이·조카가 걸리면」 하는 부모 세대(40~60대)의 불안 |
| 2 | **「시급 5만 엔」 숫자의 비현실감** | 지적(호기심) | 일반 아르바이트 시급의 수십 배. 「어떻게 그런 돈이 가능한가」라는 구조 궁금증 |
| 3 | **「안전한 곳에서 지켜보는 위험」** | 감정(대리 체험) | 1인칭 지하 창고 시점은 공포를 안전하게 체험하게 하고, 결말 사이다가 보상이 된다 |

### 1-2. 도입 15초 훅

| 시각 | 화면 | 소리 |
|---|---|---|
| 0:00~0:02 | 암전 → 스마트폰 잠금 화면에 알림 3개가 연속으로 뜬다(실글꼴 합성: 「即日現金」「面接なし」「時給50,000円」) | 알림음 3회, BGM 없음 |
| 0:02~0:06 | 「時給 50,000円」 붉은 글자 점멸 → 손가락이 「応募する」를 누르려다 멈춘다 | 「時給、五万円。」 + 심장 박동 1회 |
| 0:06~0:11 | **결말 컷 선행**: 지하 창고 바닥의 스마트폰 수백 대 위를 손전등이 훑는다(CCTV 질감) | 「この求人に応募した青年は、一週間後……」 |
| 0:11~0:15 | 철문이 닫히는 실루엣 → 질문 카드 「彼は、なぜ消えたのか」 | 저음 임팩트 → 정적 0.5초 |

원본은 결말 장면을 처음에 보여 주지 않는다. 제0장(가장 충격적인 장면 선행)에 맞춰 3장의 스마트폰 더미 컷을 0:06으로 당겼다.

### 1-3. 이탈 위험 구간과 전환 장치

| 구간 | 위험 | 장치 |
|---|---|---|
| 1:00~1:20 | 「오늘 이 시간에는…」 안내 문구가 길다 | 원본 2문장을 1문장으로 줄였다(정제본 반영) |
| 2:00~3:00 | 조건 3가지 = 정보 나열 | 조건마다 화면 전환 1개(폰 압수 바구니·안대·서약서 서명 손) + ひとつ·ふたつ·みっつ 리듬 |
| 3:00~3:40 | 2장 끝 긴장 부족 | 복선 한 줄(출발 전날 밤 전화)로 궁금증을 남김(정제본 반영) |
| 5:00~6:00 | 3장 공포 묘사가 길어 피로 | 4~5초마다 컷 교체 + 완전 정적 0.8초 1회 |
| 7:00 | 반전 직전 이탈 | 「……でも、ここで終わりではありませんでした。」 + 0.8초 정적 → 무전음(광고 지점 후보) |
| 9:00~ | 사이다 직후 이탈 | 아웃트로 첫 문장을 교훈이 아니라 행동 요청(「身近な人に一言」)으로 바꿔 댓글 유도 |

### 1-4. 유지율 경고와 수정안 (총괄 기획자 책임)

1. **플롯 모순**: 원본 4장의 「자발적으로 들어간 것이 아니라 경찰이 심은 함정 수사」는 2장의 「탐욕에 끌린 지원」과 충돌한다. 모순 지적 댓글이 상위에 오르면 신뢰가 떨어진다. → 정제본에서 「출발 전날 경찰 상담 전화」 복선으로 고쳤다.
2. **「실화」 오인**: 실명 기관 기록 + 가명 인물은 실제 사건으로 오인된다. YouTube 오해 유발 정책과 명예 문제가 있다. → 일반 명칭 + 화면 하단 フィクション 표기.
3. **길이 11:30**: 12분에 가까우면 중반 이탈이 늘어난다. → 정제본 약 10:30.
4. **영상 소재 비용**: 지하 창고·승합차·기동대 진입은 AI 생성 결함(무기·제복 글자·다수 인물)이 잦은 소재다. 진입 장면은 실루엣·역광·손전등 빛줄기로 처리해야 비용이 맞는다.

## 단계 2-3. 댓글·공유 감정 포인트 검증

| 위치 | 감정 | 기대 댓글 | 판정 |

## 단계 3. 오디오·비주얼·템포 타임라인 가이드

음성: 내레이터 1인 + 켄타 독백 배역 1인. 내레이터는 채널 내레이터 Lloyd(따뜻한 톤)보다 차가운 저음을 오디션. 속도 1.0~1.05, 문장 간 0.3~0.5초, (間) 표기는 0.8~1.2초.

| 시간 | 음성 톤 | BGM | 효과음 | 화면 템포 |
|---|---|---|---|---|
| 0:00~0:15 | 낮고 느리게(0.95) | 없음 → 0:11 저음 임팩트 | 알림음×3, 심장 박동, 철문 | 컷 2~4초 |
| 0:15~1:20 | 차분·담담(1.0) | 미스터리 앰비언트(피아노 단음 + 패드), 볼륨 0.36 | 도시 소음 원경 | 컷 3~5초 |
| 1:20~2:30 | 약간 빠르게(1.05), 조건은 끊어 읽기 | 같은 곡 + 저음 펄스 | 조건마다 UI음 | 조건당 1컷 |
| 2:30~3:40 | 켄타 독백은 젊은 남성(가볍게) | 펄스 빠지고 정적 → 복선 뒤 현 트레몰로 | 전화 발신음 1회 | 4~5초 |
| 3:40~5:30 | 속삭이듯 낮게(0.95) | 저주파 드론 + 금속 마찰, 0.40 | 차 문, 발소리 울림, 형광등 지직 | 1인칭 손전등, 5초 이하 |
| 5:30~7:20 | 독백은 숨소리 섞어 떨리게 | 드론 상승 → 7:00 직전 완전 정적 0.8초 | 심장 박동 가속, 철문 닫힘 | 3초 이하로 빨라짐 |
| 7:20~8:30 | 톤 반전, 힘 있게(1.05) | 무전 노이즈 → 타격형 퍼커션 | 발신기 삑, 무전, 철문 파괴 | 화이트 플래시 전환 1회 |
| 8:30~9:40 | 단정하게 | 오케스트라 해결 화음 | 수갑, 뉴스 징글(자작) | 4~5초 |
| 9:40~10:30 | 따뜻하게(0.95) | 피아노 테마 | 없음 | 정적 화면 + 버튼 애니메이션 |

허점과 보완: ① 단일 내레이터 10분은 단조롭다 → 켄타 독백 3줄을 별도 배역으로. ② 3장 소리가 계속 커지기만 하면 피로하다 → 5:10과 7:00에 두 번 정적. ③ 자막은 한 이벤트 2줄·16~20자(제17장 2), 공포 구간 핵심 낱말만 붉은색.

### 4-2. 썸네일 기획

- **구도**: 왼쪽 2/3 어두운 지하 창고, 바닥의 스마트폰 더미에 손전등 빛 원 하나. 오른쪽 1/3에 겁에 질린 청년 얼굴(실사, 렌즈 응시, 땀 한 줄기). 오른쪽 아래는 재생 시간 표시 때문에 비운다.
- **문구(3줄 이내)**: 위 노란 큰 글자 「時給5万円」, 아래 흰 글자 「応募したら…」, 붉은 도장 「闇バイト」.
- **색**: 검정·청회색 바탕에 노랑(돈)·빨강(위험) 2색만. 168px 축소본에서 「5万円」이 읽혀야 한다(제13장 5).
- **B안**: 구인 앱 화면 클로즈업(「時給50,000円」 + 「応募する」 버튼)에 손가락이 다가가고, 화면 반사에 철문이 비친다.
