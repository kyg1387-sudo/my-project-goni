## 5. 화면 속 일본어 글자 (규격서 제2장 1의 실전판)

- 생성은 **무지 면(빈 종이·빈 명판)** 으로, 글자는 **실글꼴 합성**: 예고장·통지 Zen Old Mincho, 아이 편지 Hachi Maru Pop(줄마다 크레용 색·기울기), 아내 글귀 Klee One(연필), 호수판은 스테인리스 판을 **그려 넣기**.
- 블렌드: 먹·연필·크레용 = 곱하기, 빨간 종이 흰 글자 = 종이 밝기 비례, 불투명 판 = 장면 밝기 맞춤. 글자에도 필름 그레인.
- 영상 추적: 면 자체(문·어두운 벽)는 무늬가 없어 원근 추정이 무너진다 → **화면 전체 특징점의 이동·회전·확대(4자유도) + RANSAC + 급변 무시 + 평활**.
- 도구: `scripts/ja_text_overlay.py still|video <장면> <입력> <출력>` (`QUADS` = 키프레임 좌표 네 모서리, 격자 이미지를 그려 읽는다).
