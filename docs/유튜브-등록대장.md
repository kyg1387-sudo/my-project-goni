# 유튜브 등록 대장 (본편·쇼츠 등록일자·시간)

이 저장소에서 제작한 모든 영상의 **유튜브 등록(공개) 일자·시간**을 한 곳에 기록한다.
규칙: 작품을 유튜브에 올리면(예약 포함) 그 즉시 이 표의 「실제 등록」칸을 채우고 커밋한다 —
사용자 요청 2026-10-18 ("본편과 쇼츠 등록일자와 시간을 지침서에 넣어줘").
AI는 유튜브에 접근할 수 없으므로(네트워크 차단) 실제 등록 시각은 **사용자가 알려 준 값만** 적는다.
시각은 모두 **KST** 기준(일본판은 JST 병기, KST=JST).

표기: `완성(커밋)` = 완성본이 저장소에 커밋된 시각(제작 완료 기준, 자동 확인 가능).
`예약 권장` = 업로드 가이드에 적힌 권장 예약 시각. `실제 등록` = 유튜브 공개/예약 시각(사용자 확인 값).
`URL`은 등록 후 채운다.

## 4. 기록 절차 (매 작품 필수)

1. 완성본 전달 시 이 파일에 행을 추가한다(완성 커밋 시각은 `git log -1 --format=%ci -- <파일>` +9h).
2. 사용자가 업로드·예약을 마치면 실제 등록 일자·시간·URL을 알려 주고, AI가 표에 기입해 커밋한다.
3. 쇼츠는 편마다 한 행씩 쓴다(하루 1편 리듬 확인용).
4. 48시간 뒤 반응 확인(유튜브 분석)은 각 업로드 가이드의 "게시 후 48시간 확인" 절을 따른다.
