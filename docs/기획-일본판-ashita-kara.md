# 「明日から来なくていい」 일본판 기획·제작안 (ashita-kara)

사용자가 보내 준 일본 유튜브(スカッと系) 완성 대본을 이 파이프라인의 제작 자산으로 변환했다.
**아직 생성(과금) 실행은 하지 않았다.** 아래 "결정 필요 항목"에 답을 주면 바로 1단계(장면 생성)를 돌릴 수 있다.

## 0. 생성된 파일 (전부 무과금)

| 파일 | 내용 |
|---|---|
| `skits/ashita-kara.md` | 최종 대본 — 일본어 TTS 원문 + 한국어 병기, 장면 번호 |
| `scripts/build_ashita_kara.py` | 대본·장면·자막·오디오 설정 생성기 (수정은 여기서, 실행하면 전부 재생성) |
| `scripts/scenes/ashita-kara.json` | 장면 프롬프트 72개 (규칙집 5블록 양식, 10초 57 + 5초 15) |
| `subs/ashita-kara.ass` | 일본어 구움 자막 63줄 + 화면 카드 9장 (Caption/Title) |
| `subs/ashita-kara.ko.srt` | 한국어 CC (유튜브 자막 업로드용, 화자 접두 포함) |
| `scripts/audio/ashita-kara.json` | 목소리·감정·속도(전 63줄 지정, 빈 줄 0) · 장면별 화자 · 현장음 · BGM |
| `docs/톤연출표-ashita-kara.md` | 줄별 톤 연출표 (규칙 8-2) |

규모: **72장면 · 10분 45초 · TTS 63줄(약 2,300자) · 립싱크 대상 24장면(230초)**

검증(무과금) 결과: 화자-화면 불일치 0건, 한 장면 다화자 0건, 대사 겹침 0건, 감정·속도 미지정 0줄,
TTS 본문에 영문·숫자 0건(백억 엔→百億円 등 전부 일본어 표기), 자막 렌더 확인(붉은 카드 중앙·대사 하단).

## 1. 원 대본에서 바꾼 것 (왜)

1. **전부 일본어 TTS 대본으로 번역** — 원문은 한국어 내레이션 + 일부 일본어였다. 일본 시청자용이므로 목소리는
   전부 일본어여야 하고, 한국어는 CC 자막으로만 제공한다. 일본어 원문 옆에 한국어를 병기해 검토할 수 있게 했다.
2. **"시청자의 분노와 도파민은 최고조"(메타 서술) → 「皆さんなら、この仕打ちを許せますか？」** — 일본 スカッと
   채널의 관례대로 시청자에게 직접 묻는 문장으로 바꿨다(댓글 유도 효과).
3. **OCR/SPD/Access Denied 같은 영문 약어 제거** — TTS가 영어로 읽거나 흔들린다(EP2 교훈 ⑩). 過電流継電器·
   サージ保護装置로 풀어 쓰고, 「アクセス拒否／不正改造警告」는 화면 카드(자막)로만 보여 준다.
4. **대사 추가(8줄)** — 10분 30초를 채우려면 원문 대사 5줄로는 부족했다. 사토의 반격 복선(「その言葉、忘れないで
   ください」 / 해고 직후 발주처와 통화), 전무의 냉소, 서버실 패닉, 시운전 강행, 타나카의 애원을 추가했다.
   원문의 핵심 대사(「今すぐ俺の前から消えろ」「明日から会社に来るな」「君たちの方だろう？」)는 그대로다.
5. **인물 4명으로 압축** — 사토·타나카·야마모토 전무(=타나카의 삼촌, 원문의 '전무'와 '대표'를 합침)·타카하시
   본부장(발주처). 경찰·감사관은 실루엣·뒷모습(규칙집 9: 적대·배경 인물은 실루엣)으로만 둔다.
6. **화면 속 글자 전부 제거** — 스마트폰 부재중 전화 화면, 명함 글자, 모니터 경고 문구는 생성 모델이 못 쓰므로
   (CLAUDE.md 비용 원칙 4) 프롬프트에서 무지로 지시하고 자막 카드로 대체했다.
7. **한 음절 감탄사 없음, 모든 대사 장면은 "가슴 위 구도·손 없음"** — omnihuman 팔 추가 사고(교훈 ⑪) 예방.
8. **콜드 오픈 45초** — 경찰차 앞 타나카 → 고함 대사 → 쫓겨나는 사토 → 붉은 경고 모니터 → 타이틀.
   원문의 "낙하산 상사 수갑" 훅을 유지하되 30초 안에 대사 1줄을 넣어 "소리"로도 훅이 걸리게 했다.

## 3. 제작 시작 전 결정 필요 항목 (사용자 답변 필요)

① **기준 초상 → image-to-video 방식** (CLAUDE.md "다음 작품 시작 시 안내"): 인물 4명의 기준 초상을 먼저 1장씩
   만들고(각 $0.1 이하) 그 이미지로 장면을 만들면 얼굴·의상이 고정돼 재생성 비용이 크게 준다.
   **단, 이 저장소의 `generate_video.py`는 현재 텍스트→영상만 지원한다.** i2v를 쓰려면 스크립트에 refs 입력을
   추가해야 한다(무과금 작업, 반나절). 채택 여부를 알려 달라 — 권장: 채택.
② **카메오** — 본인 정면 사진을 주면 사토(주인공, 40대 후반 기술자) 또는 타카하시 본부장을 본인 얼굴로 만들 수
   있다(얼굴 교체, 소액). 일본판이므로 명찰 "김영곤"은 넣지 않는 것을 권장(일본 회사 배경과 맞지 않음).
   원하면 가타카나 「キム」 명찰로 가능.
③ **목소리 오디션** — 현재 설정은 MiniMax 기본 목소리(내레이터 Deep_Voice_Man, 사토 Determined_Man, 타나카
   Casual_Guy, 전무 Elegant_Man, 본부장 Imposing_Manner)에 language_boost=Japanese. 일본어 자연스러움은
   목소리마다 차이가 크므로 **본편 전 후보 목소리로 핵심 대사 3줄(사토 마지막 대사·타나카 해고 통보·내레이션
   첫 줄)을 시험 생성**해 들어 보고 확정하자(총 $0.5 이내). 내레이터는 ElevenLabs(일본어 v3)가 더 좋을 가능성이
   높다 — 비교 청취 원하면 말해 달라(EP 시리즈 내레이터 EL 음성은 한국어용이라 재사용 불가).
④ **채널 전략(중요)** — 일본어 본편을 **한국어 채널(미담이야기)에 올리면 안 된다.** 유튜브는 채널 단위로
   시청자 언어·관심사를 학습하므로 기존 한국 구독자에게 일본어 영상이 노출되면 이탈률이 올라가 채널 전체 추천이
   줄어든다. **일본 전용 새 채널**을 만들고(무료, 같은 구글 계정에 브랜드 채널 추가), 채널명·설명·기본 언어를
   일본어로 설정한다. 한국어 CC는 보너스로만 붙인다.
⑤ **콜드 오픈 재사용 장면** — 3번 장면(타나카 고함)과 26번 장면(2막의 같은 대사)은 프롬프트가 같다.
   파이프라인이 장면마다 새로 생성하므로 두 번 과금된다(약 $0.5). 1회 생성 후 복사하려면 생성 뒤 out/ 파일을
   복사하는 수작업이 필요하다 — 소액이므로 그냥 두 번 생성하는 것을 권장.

## 4. 제작 순서 (결정 후)

1. (선택) 기준 초상 4장 생성 → 사용자 확인.
2. 목소리 오디션 3줄 → 사용자 청취 → `scripts/audio/ashita-kara.json`의 voices 확정.
3. `콩트 영상 생성` 워크플로: `skit=ashita-kara` (72장면, 약 1~2시간).
4. 전 장면 프레임 검수(시작·중간·끝 3지점 + 무인 지시 장면 인물 유무 + 로케이션 대조) → 불합격 장면만
   `scenes_only`로 부분 재생성.
5. `콩트 영상 자막 입히기` 워크플로: `skit=ashita-kara, source_run_id=<3번 run>, add_audio=true, lipsync=true`.
   먼저 `qc_tts=true`로 **일본어 언어 검사**(이번에 qc_tts.py에 `--config` 추가, language_boost=Japanese면 자동으로
   가나·한자 비율 검사)를 돌려 외국어 혼입 0건 확인 후 믹싱.
6. 완성본 시사 → 쇼츠 5개 컷(아래) → 업로드.

이번에 파이프라인에 추가한 기능(무과금, 기존 작품 호환 유지):
- 장면별 길이 `{"prompt", "duration": 5|10}` 지원(generate_video.py, slice_scenes.py) — 인서트·완충 컷을 5초로 만들어 비용 절감.
- `silent_styles`(화면 전용 자막 스타일 → TTS 제외) 지원(generate_audio.py).
- 현장음 프롬프트가 빈 장면은 현장음 생략(인물 장면의 말소리 혼입 방지).
- qc_tts.py 일본어 검사(`--lang ja` 또는 설정의 language_boost로 자동).

## 6. 글로벌 진출 가이드 (업로드 단계용 — 매 작품 필수 안내)

이번 작품은 **일본어가 1차 언어**이고 한국어가 2차 자막이다.

① **자막 업로드 순서(처음 하는 분 기준)**
1. studio.youtube.com → [만들기] → [동영상 업로드] → 완성본 선택.
2. 세부정보: 제목·설명은 위 일본어 원문 붙여넣기. **동영상 언어: 日本語** 로 반드시 설정(이게 추천 지역을 정한다).
3. [아동용 아님] → [다음] → 공개 설정: **예약** (일본 시간 토·일 19:00~21:00 = 한국 19:00~21:00, 시차 없음).
4. 업로드 후 좌측 [자막] → 해당 영상 → [언어 추가] → **한국어** → [업로드] → "타이밍 포함" → `subs/ashita-kara.ko.srt`.
   (일본어는 영상에 구워져 있으므로 CC는 선택. 검색 노출을 위해 일본어 CC도 올리고 싶으면 말해 달라 — .srt는 즉시 만들 수 있다.)
5. [자막] → 한국어 행 [제목 및 설명] → 위 한국어 제목·설명 입력.

② **언어별 제목·설명 원문**: 5절 참고.

③ **국가별 반응 보는 법**: 스튜디오 → [분석] → [시청자층] → 상위 지역. 업로드 1주 후
   **일본 비율 70% 이상 + 평균 시청 지속시간 40% 이상**이면 알고리즘이 일본 시청자를 제대로 찾은 것 →
   2편 제작. 일본 비율이 낮으면 동영상 언어 설정·제목 키워드(スカッと 계열)를 먼저 점검.
   한국 비율이 10%를 넘으면 한국 채널에 "일본판 예고 쇼츠"를 올려 교차 유입을 노린다.

④ **반응 좋을 때 다음 단계**: (1) 같은 세계관 2편(「無能な上司シリーズ」로 재생목록화, 사토 초상·사무실 로케이션
   재사용 = 비용 절감), (2) 쇼츠 5종: 콜드오픈 45초 / 「明日から会社に来るなって言ったのは…」 명대사 / 서버실 경고
   순간 / 반전 직전(「しかし、それこそが…」)에서 끊기 / AI 제작 비하인드, (3) 영어 CC 추가(무료), (4) 반응이 폭발하면
   한국어 더빙판(TTS 63줄 교체, 약 $1 + 립싱크 재생성 $3).

## 7. 이번에 알아두면 좋은 유튜브 정보

- **일본 スカッと 장르 특성**: 시청자 다수가 30~50대 직장인, 통근 시간(07~09시)과 밤(21~23시)에 시청. 썸네일은
  **붉은 굵은 고딕 4~6글자 + 분노한 얼굴**이 표준(예: 「クビにした結果…」). 2종 만들어 A/B.
- **동영상 언어 설정이 추천을 결정한다**: 음성이 일본어인데 언어를 한국어로 두면 한국에 추천돼 이탈률이 폭등한다.
- **새 채널은 처음 5~10편이 학습 기간**: 같은 장르·같은 길이(10분 내외)·같은 요일에 꾸준히 올려야 알고리즘이
  채널 정체성을 잡는다. 장르를 섞지 말 것.
- **수익화(구독 1,000·시청 4,000시간)는 채널별**로 계산된다 — 한국 채널 실적은 일본 채널에 넘어가지 않는다.
- **픽션 고지**: 일본 시청자는 실존 기업 연상에 민감하다. 설명란 "この物語はフィクションです" 문구를 반드시 유지하고,
  회사명(大東テクノロジー)은 실존 기업과 겹치는지 업로드 전 한 번 검색해 본다.

## 8. 성장 전략 체크리스트 (매 작품 상기)

① 시리즈 세계관: 사토를 고정 주인공으로 "무능한 상사 시리즈"화(초상·사무실 재사용). 이번 편 끝 다음 화 예고 카드는
   2편 소재 확정 후 추가(지금은 구독 요청만).
② 데이터 기반 기획: 이 편의 쇼츠 5개 중 성적 좋은 훅(해고 통보형 vs 반전형)으로 2편 첫 문장 결정.
③ 본편 1 → 쇼츠 5, 매일 1개. ④ 본편은 토·일 저녁 예약(일본 기준), 쇼츠 매일. ⑤ 고정 댓글 질문(5절).
⑥ 썸네일 A/B 2~3종. ⑦ 공통 아웃트로: 이번 편은 사토 사무실 장면이 아웃트로 역할(일본판 전용 진행자는 2편부터 검토).
