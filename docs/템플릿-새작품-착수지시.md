새 세션 「새로 만들기」 첫 메시지로 아래를 복사해 붙인다. 〈 〉 두 곳만 채운다(소재 후보가 없으면 "상위 30선 기준으로 네가 제안해 줘").
2화·후속 작업 중인 세션에는 `productions/<작품>/ep2_데이터제안-지시문.md` 방식의 지시문을 따로 만든다.

```
[고니감독님 — 새 작품 착수, YYYY-MM-DD]

장르: 〈スカッと / 美談·人情 중 하나〉
소재·주제 후보: 〈한 줄, 없으면 "상위 30선 기준으로 네가 제안해 줘"〉

너는 일본 유튜브 최고의 기획 제작자이자 수석 프로듀서다(CLAUDE.md 최우선 원칙). 채팅으로 주제 → 대본 → 제작까지 함께 간다. 아래 순서로 시작하라.

0. git pull로 claude/next-bidan-1101 최신을 받고, CLAUDE.md 최우선 원칙 1~8과 제0·13·20·21장을 읽어라.
1. 데이터 먼저(최우선 원칙 7, 건너뛰면 착수 금지):
   - docs/분석/최신-채널수치.md, 최신-장르동향.md를 읽고 우리 채널 최근 3편 수치와 장르 상위 패턴을 요약.
   - python3 scripts/yt_genre_report.py "〈장르 키워드〉" --kind main --ours "〈소재 한 줄〉"
     python3 scripts/yt_genre_report.py "〈장르 키워드〉" --kind shorts
     python3 scripts/yt_subject_check.py 〈작품 가칭〉 "〈소재어1〉" "〈소재어2〉"
     python3 scripts/yt_thumb_sheet.py "〈장르 키워드〉" --long-only --tile 360 --top 9
   - 판정·구조 추정·결론 칸을 전부 채워라(근거는 상위 30선 번호·수치).
2. 착수 보고(한 번에): 「데이터 근거 3줄」 → 주제 후보 3개(상위 30선과 겹치는 반전은 제외, 각 후보에 후크 대사·반전·결말·예상 이탈 3곳) → 네 추천 1개와 이유 → 「상위 30선 대비 과감한 제안」 3개 이상(채택 시 바뀌는 것·비용·위험) → 공개일(schedule_plan.py next, 스튜디오 예약 목록 대조 전이면 잠정) → 직전 작품 보강 장 점검표(01_제작지침-적용.md, D. 데이터 대조 절 포함).
3. 내가 주제를 고르면 PHASE 1 대본: 일본어 먼저(제14장), 제0장 구간 공식(후크 0:20·광고 3:30/7:00·결말 9:30, 10~11분), 30~40초마다 열린 고리, 구간별 예상 이탈 지점 표, 논리 검수표(반전 뒤 「왜 몰랐나」를 막는 대사 줄), 제목 2단 양식 2안(제13장 6), 가상 회사명 검색 확인, 본편에 次回·구독 CTA 금지(제20장 15). 한글 번역은 검수용으로 병기.
4. 이후 모든 단계 보고는 시청자 관점 검증표(약점 3곳)·등록 일정 표·「상위 30선 대비 제안」 절·「규격 반영: 제N장 n번」을 붙이고, 유료 실행 전에는 규모·비용을 먼저 보고해 승인받아라.
5. 3대 기록(실증 장·제작비용·캘린더)과 qa_final.py --work 9항목 PASS 없이는 최종 전달 금지.

지금 1번부터 실행하고 2번 착수 보고를 올려라.
```

## 공개 영상 주기 관리 요청 문구(고니감독님 확정 2026-11-06, 제21장 8 — 자동 작업과 별개로 아무 세션에서나 붙여 넣는다)

### A. 채널 전체 주간 관리(개선안까지)
```
[고니감독님 — 공개 영상 주기 관리, CLAUDE.md 제21장 8·최우선 원칙 8]
git pull로 claude/next-bidan-1101 최신을 받고 다음을 실행하라.
1. python3 scripts/yt_public_report.py → python3 scripts/yt_weekly_brief.py
2. 최근 공개 본편 2편의 장르로 python3 scripts/yt_genre_report.py "<키워드>" --kind main (1~2회)
3. docs/분석/주간관리-<오늘>.md 5절 「부족한 부분·보완안」 3개 이상(부족한 수치·보완안·내가 스튜디오에서 할 작업·기대 효과·근거 번호), 6절 다음 소재 2개 이상을 채워라. 썸네일 교체안이 있으면 yt_thumb_sheet.py로 대조 시트를 만들어 첨부.
4. docs/분석·docs/시리즈-성과.md 커밋·푸시 후 보고: 데이터 근거 3줄 → 부족한 부분 3개와 보완안(스튜디오 작업은 번호 목록) → 다음 소재 제안 → 파일 경로. 유료 생성·유튜브 설정 변경은 하지 말고 제안만.
```

### B. 특정 작품 개선(공개 +7일·+30일 등)
```
[고니감독님 — 『〈작품명〉』 공개 후 개선 점검]
git pull 후 docs/분석/최신-채널수치.md와 docs/분석/comments/ 를 읽고 『〈작품명〉』 본편·쇼츠 4편을 점검하라.
1. 조회/일·좋아요/조회·댓글·쇼츠→본편 전환을 같은 장르 상위 30선(yt_genre_report.py "<장르 키워드>" --kind main)과 비교해 부족한 축을 수치로 짚어라.
2. 개선안을 즉시 적용 가능한 것(제목 2단 양식 교체안 2개·썸네일 교체 A/B + yt_thumb_sheet.py 대조 시트·설명문 첫 줄·고정 댓글·태그·재생목록·카드/엔딩 화면)과 다음 작품에 반영할 것으로 나눠 표로 내라. 각 항목에 근거(상위 30선 번호·우리 수치)와 기대 효과.
3. 썸네일 교체본이 필요하면 1280x720 JPG로 만들어 전달하고, 제목·설명문은 그대로 복사해 붙일 수 있게 적어라.
4. 결과를 docs/분석/개선점검-〈작품명〉-<오늘>.md에 저장하고 docs/시리즈-성과.md 메모 칸을 채운 뒤 커밋·푸시. 유료 생성은 내 승인 전 금지.
```
