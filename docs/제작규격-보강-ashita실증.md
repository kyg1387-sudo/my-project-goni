## 2. 제작 중 발견한 결함과 대책 (●)

### PHASE 1 대본·음성
- ● Lock 길이가 기준(9:40) 미달·광고 지점 어긋남 → 대본 보강 줄(P1~P10)로 이야기 비트를 채워 해결. **Lock 전에 구간 시각표로 미리 계산.**
- ● 회사명 재녹음 시 이름이 길어져 줄 길이가 늘어남 → **Lock 타임라인은 다시 계산하지 않는다.** 새 음성을 무음 정리 후 원래 슬롯(다음 줄 시작 전)에 맞춰 배속(≤1.15, 내레이션 1.2 이내). 같은 음절 수의 대체명을 고르면 배속이 작다.
- ● 따옴표·괄호가 가나 변환 매칭을 막음(“元”社員) → 태그별 가나 매핑(TAG_KANA).

### PHASE 2 시트
- ● 표정 칸 하나가 다른 사람으로 나옴 → 표정 칸도 정면 셀 대조 필수(★5).
- ● 로케이션 시트에 사람·포스터·분할선·간판 → 무인·무지 고정 문장, 문제 칸은 크롭·재생성.
- ● 주인공·악역에 귀걸이가 전이 → 「no earrings」 고정.

### PHASE 3 샷 설계
- ● 대사 시작 컷의 화자가 비립싱크 컷에서 입을 보임(48컷 중 27컷) → 「입 가림」을 생성기 고정 문장 + 검수 항목으로(제10장 2).
- ● 정지 컷 86개로 생동감 부족 → 사람 컷 i2v 기본(★13).
- ● BGM 구간 사이 간격 0.5초 → 조립이 중단됨. **간격 1.0초 이상을 생성기에서 미리 검사**(build_ashita_phase3.py assert).

### PHASE 4 키프레임 (생성기 교훈 ①~⑱, `scripts/build_ashita_keyframes.py` 주석)
| 결함 | 대책 |

| 위아래·좌우 검은/흰 띠 | `kf_letterbox_fix.py`(양쪽 모두 검사 — 한쪽만 자르면 반대쪽 흰 띠가 남음) |
| 콘솔·벽 종이·간판의 가짜 글자 | `kf_glyph_blur.py` 얕은 심도 흐림(영역 JSON 기록) |
| 대사 CU가 고함치는 입으로 나옴 | 분노는 눈·이마·턱으로, 입은 닫힘 |
| 낮 로케이션 참조가 암전 장면을 낮으로 만듦 | 조명 고정 문장 + 같은 장면 승인 컷을 **인물을 잘라낸** 조명 참조로 |
| 조명 참조 컷 속 인물이 옮겨 붙음 | 조명 참조는 무인 판(`S24-light.png`) |

| 손·소품 인서트에 얼굴이 나옴 | 인서트 고정 문장(얼굴·머리 없음) |
| 같은 장소 연속 컷이 같은 구도 | 앵글 고정 문장(하이·오버헤드·측면) |
| 일본어 합성용 면에 가짜 글자 | 무지 면 고정 문장 |
| 소품만 참조한 인서트가 엉뚱한 장소에 놓임 | 같은 장면 로케이션 참조 추가 |

| 주인공 소품(버튼)의 가짜 글자를 흐림 → 빨간 얼룩, 인서트가 원경으로 나와 몸 없는 팔 | 진짜 인서트 고정 문장(손·소품만 화면 가득, 글자 없음)으로 재생성 (★19) |
| 대사 키프레임 얼굴이 작음 | `kf_face_frame.py`(얼굴 화면 높이 1/4 이상, 전경 어깨 쪽 `fg` 지정해 유지) |

### PHASE 5 영상
- ● i2v 중 화자가 카메라 쪽으로 돌아봄·실루엣이 밝아져 얼굴 노출 → 동작 문장 「등을 카메라에 둔 채」, 실패 컷은 정지 푸시인 폴백(`I2V_FALLBACK`).
- ● B안 i2v 59컷 실증(R63·R64): **말하는 사람의 뒷모습·옆모습 컷**은 「머리는 같은 각도 그대로, 카메라 쪽으로 돌지 않음」을 넣어 다시 만들어도 8컷 중 7컷이 또 돌아봄(입 노출·의상 변화). 고개 동사(으쓱·끄덕·의자 회전·기대기)를 빼도 같음. → **다음 작품은 비립싱크 화자 컷을 처음부터 정지 + 편집 카메라로 설계**하고, i2v는 듣는 사람·말하지 않는 인물·걷는 뒷모습·손 인서트에만 쓴다(재생성 비용 절약). 판정은 **실제 쓰는 길이(샷 길이)** 안에서만 한다(5초 클립의 뒤쪽 돌아봄은 잘려 나감).
- ● B안에서 정지 컷이 i2v로 바뀌면 마무리 스크립트의 정지 재패치(STILL_REDO)와 편집 효과(더치 등)를 다시 맞춘다(S19c 더치 7°를 정지 카메라에서 편집 카메라로 옮김).
- ● OmniHuman 8초 상한 → 긴 진행자 멘트는 컷을 나눔(4컷).
- ● 진행자 OmniHuman 가장자리 손 잔상(★12) → 크롭.
- ● 일본어 글자 합성 6곳을 조립 전에 빠뜨림 → **PHASE 4 마감 체크리스트에 「ja_overlay 컷 합성 완료」를 넣는다**(`ashita_ja_overlay.py`).

### PHASE 6 조립·마무리
- ● 후크 0~4초 완전 무음(−60dB) → 드론·심장 박동 로컬 믹스(`finalize_ashita.py`).
- ● 후크 재사용 컷이 정지 화면 → 본편 립싱크 구간을 가져와 음성과 함께 얹음.
- ● 검은 카드 클립이 20KB 미만이라 깨진 파일로 판정 → 옅은 그레인.
- ● 정전 구간 평균 밝기 9~35/255 → 휴대폰에서 검정(★20). 곡선으로 중간 톤만 들어 올림(평균 약 2배), 전경 소품이 가린 컷은 당김(punch).
- ● 로컬 사전 추산이 `out/`를 지워 진행 중인 마무리 렌더링이 중단됨(R59) → 마무리 렌더링 중에는 `out/`를 쓰는 다른 작업 금지.
- ● burn 실행 중 푸시 금지(규칙 유지). 조립 후 마무리는 로컬(`finalize_ashita.py --outro-only` 로 아웃트로만 다시).
