**효과음 큐** (폴리 = 실제 소리, 만화풍 효과음 금지 · 크기는 대사 평균 대비 dB)

원칙 — "들리지만 의식되지 않게":
1. 대사와 겹치는 효과음은 대사 -18dB 이하, 대사 없는 순간의 효과음은 -10~-12dB.
2. 효과음은 대사 사이 빈 틈(앞침묵 구간)에 배치 — 대사 첫 음절과 겹치지 않게 0.2초 이상 띄움.
3. 강한 소리는 작품 전체에 2개만(문 열림, 저음 임팩트). 나머지는 전부 "있는 듯 없는 듯".
4. 폴리 효과음은 무료 라이브러리 원샷(OtoLogic·DOVA 효과음 중 실사풍)을 시점 지정 배치 — mmaudio 장면 현장음과 같은 소리를 이중으로 넣지 않는다.
5. 효과음이 울리는 0.5초 동안 BGM을 3dB 살짝 낮춰 서로 부딪치지 않게 한다.

| 시점 | 효과음 | 크기 | 거슬림 방지 메모 |
|---|---|---|---|
| 0:00 | 천이 거칠게 당겨지는 소리 | -12dB | L1 시작 0.3초 **전**에 끝나게 — 첫 대사를 가리지 않음 |
| 0:04 | 휴대폰 촬영음(찰칵) | -14dB | L2 대사 **뒤** 빈 틈에. 날카로운 고음은 EQ로 깎음 |
| 0:28–1:10 | 거리 소음(로우패스 4kHz, 말소리 없음) | -24dB 깔기 | 내레이션 아래 바닥 소리. 경적·사이렌 없는 소스만 |
| 1:10–7:10 | 레스토랑 룸톤(식기 달그락·공조 험) | -28dB 깔기 | 웅성거림 금지. 거의 안 들리는 수준 — 없으면 "빈 방"처럼 들림 |
| 3:40 | 찻잔을 식탁에 내려놓는 소리 | -12dB | 무언 동작 컷에서 단독 — L11 전 0.5초 비움 |
| 4:40 | 냄비에서 우동 국물을 붓는 소리 | -14dB | 내레이션 N8 문장 사이 쉼에 맞춤 |
| 6:55 | 심장박동 2회 | -20dB | L21 앞침묵 1.5초 안에만. 작품 내 1회 |
| 7:10 | 문 열림 + 구두 소리 3걸음 | -8dB | 정적 직후라 작게 넣어도 크게 들림 — 더 키우지 않음 |
| 7:14 | 저음 임팩트 | -6dB, 150Hz 이하 | L22가 **끝난 뒤** 0.2초에. 고음 없음 = 이어폰에서도 안전 |
| 8:35 | 土下座 — 무릎이 바닥에 닿는 둔탁한 소리 | -16dB | 무언 동작 컷 단독, L29 전 1.2초 비움 |
| 9:20 | 젓가락이 우동 그릇에 닿는 소리 | -16dB | 감동 구간이라 가장 작게. B3 피아노와 박자 어긋나지 않게 |
| 10:10–10:50 | 차 실내음(낮은 엔진 험) | -26dB 깔기 | 내레이션 아래 바닥 소리 |

- 최종 마스터: 전체 -14 LUFS, 최대 -1 dBTP (이어폰 시청 배려).
- 정적·효과음 큐·덕킹·마스터링은 현재 믹서(`generate_audio.py`)에 없는 기능 — 믹서 업그레이드(무료 코드 작업) 후 적용.

## 전환 연출 메모 (규칙 8-1)

- S#0 정지 컷 → 자막 카드 → 타이틀: 디졸브 0.5초
- S#1 몽타주 내부 전환: 디졸브 0.5초, 거리 소음 브리지
- L18 → 중반 예고 카드: 間宮 비웃는 얼굴 여운 0.8초 → 하드 컷(긴장 유지)
- L22 직전: 정적 1.0초는 컷 없이 유지 → 문 열림
- L31 → 지배인 리액션 1초(고개 떨굼) → L32
- S#8 → S#9: 무인 완충 컷(식은 우동) 2초, 디졸브
- S#10: 디졸브 0.6초로 진입, 엔딩 카드까지 B3 이어짐
