# 『地下倉庫の伝票』(#02) 시청 유지율 검수 의견 정밀 분석 (2026-10-09)

고니감독님이 전달한 외부 검수 의견 5건을 실제 타임라인·자막 파일·오디오 설정과 대조한 결과와 처리안. 수정 번호는 #02 수정 목록(7~11)으로 이어진다.

## 1. 0:23~0:30 암전 구간 — **지적 타당, 수정 7(무과금)**
- 실측: S01g 『地下倉庫の伝票』 카드 22.16~25.22 + S01h 「二か月前」 25.22~29.03, 앞뒤 fadeblack 1.0/0.6/0.8초 → **검은 바탕 약 8.6초**(카드 2장 + 페이드). BGM 1구간이 22.4초에 끝나고 2구간이 29.9초에 시작해 **음악도 7.5초 비어 룸톤만** 남는다(1차 검수 무음 지적과 같은 구간).
- 처리안(타임라인·대사 동결 유지, 길이 변화 0):
  1. S01g: 암전 대신 **직전 후크 컷(S01f 전표 ECU) 정지 프레임을 블러**해 바탕으로 깔고 타이틀을 올린다(3.06초).
  2. S01h: **S02a(2개월 전 발표회장) 첫 프레임으로 디졸브**하며 화면 좌하단에 「二か月前」 작은 자막이 0.4초 떴다 2.4초에 사라진다(3.81초). 전환은 fadeblack → fade(디졸브 0.5)로 바꿔 검은 화면은 페이드 순간 **최대 0.5초**.
  3. BGM 1구간 끝을 22.4 → 29.9초로 늘려 타이틀 위에도 음악이 이어지게 한다(캐시 재사용, 재과금 0).
- 왜 길이를 줄이지 않나: 카드 길이를 줄이면 PHASE 1 Lock(음성 실측 타임라인)과 자막·OmniHuman 캐시가 전부 밀린다. 화면만 바꾸면 리듬은 유지하면서 「검은 화면 2초 이내」 요구를 충족한다.

## 2. 일본어 자막 레이아웃(0:54~0:59 등) — **부분 타당, 수정 8(무과금)**
- 실측: 자막 이벤트끼리 겹쳐 표시되는 구간은 0건, 행간도 정상. 다만 **3줄 자막 8건, 줄당 16자 초과 60/65건, 최대 33자**(생성기 줄바꿈 한계 19자 + 긴 문장). 0:54 내레이션이 25/9/21자 3줄이라 「겹쳐 보인다」는 인상을 준 것으로 판단.
- 처리안: 자막 생성기에서 **한 이벤트 = 최대 2줄 × 16자**로 문장 호흡(、。……)에서 분할하고, 분할된 조각은 글자 수 비례로 시간을 나눠 연속 표시(음성은 그대로). 폰트 54→58로 키워 모바일 가독성 확보. 재굽기 때 반영(무과금).

## 3. TTS 감정 완급 — **타당, #03부터 기본 적용(수정 9: #02는 보류 권고)**
- 실측: #02 음성은 Typecast ssfm-v30에 **줄별 emotion_preset·intensity·tempo를 이미 지정**해 녹음했으나(`build_tts.py`), 검수자가 평이하게 느낀 구간(곤도 비아냥·사오리 독백)은 강도가 낮았다.
- #02에 지금 적용하면: 재녹음 줄의 길이가 바뀌어 Lock 타임라인·자막·OmniHuman 캐시(해당 CU 재생성 0.16/s)가 연쇄로 바뀐다. 곤도 OMNI 9컷 + 사오리 독백 6컷 재생성만 **약 12~15달러** + 재조립 2회. 효과 대비 비용이 커 **#03부터 PHASE 1 규칙으로 적용**을 권고: 악역 = angry/sneer intensity 0.7↑ + tempo 1.05~1.1, 주인공 독백 = sad intensity 0.6 + tempo 0.92 + 줄 앞 0.4초 한숨 호흡(「……」) 삽입, 오디션 때 내레이션과 **A/B 청취 비교**를 필수로.
- 감독님이 #02에도 원하시면 가장 효과 큰 3줄(S05 「カビてろ」, S03 「俺のもの」, S09 사오리 독백 1줄)만 재녹음·재생성(약 3~4달러)하는 축소안을 제안.

## 4. 효과음(Foley) 보강 — **타당, 수정 10(소액)**
- 실측: 생성기에 효과음 13개(유리 파손 6.83s·엘리베이터 문 133.6s·도장 3회·심장박동·클릭·코르크·플래시 등)가 **설계되어 있었으나 조립 도구가 섞지 않았다**(`_효과음`은 메모 필드). 즉 완성본에 효과음 0개 — 검수자 지적과 정확히 일치.
- 처리안: ① 효과음 소스는 기존 경로(ElevenLabs 사운드 생성, 곤도 폭소 때 사용)로 **16개 생성**(13 + 박수 0:41 + 철문 1:20 + 형광등 깜빡임 2:52), ElevenLabs 크레딧 약 16×1~3초, 달러 환산 1달러 미만. ② `chika_master.py`에 타임코드 믹스(−18~−12 dBFS, 대사 구간은 −6 dB 더 낮춤)를 추가해 마스터링에서 로컬 합성(무과금). ③ 규칙화: 효과음 목록은 설계와 동시에 생성·믹스까지 자동.

## 5. 후반 사이다 진입 타이밍 — **이미 충족, 수정 불요**
- 실측: 수모 구간 0:31(좌천 발령)~3:30(지하에서 전표 발견·미야모토 접근) = **약 3분 = 본편의 27%**(아웃트로 제외 11:08 기준). 3:31.7에 BGM이 「불안한 피치카토」 → 「조사·탐정 비트」로 전환되고, 같은 지점이 1차 광고 설계점(3:30.1)이다. 검수자가 요구한 「중반 전 전표 발견 + BGM 전환」 구조를 이미 갖췄다.
