## 5. 파이프라인 적합성 점검

### 5-1. 규칙 충돌 (사용자 결정 필요)
1. **언어**: CLAUDE.md는 「한국어 전용」(TTS language_boost=Korean, 장면 프롬프트 「한국어로 말하는 입 모양」, 오디오 언어 검사). 이 작품은 **일본어 원어 작품** → 규칙의 「한국어」를 「작품 언어」로 바꿔 적용해야 함:
   language_boost=Japanese, 프롬프트 「日本語を話す口の動き, no English」, 언어 QA 기대값 ja, 다국어 CC는 **한국어·영어** 자막이 1순위.
2. **내레이션 화자**: 규칙 2는 「배역과 구별되는 3인칭 내레이터」. 이 대본은 **사오리 1인칭 독백**(스카ッと 장르 표준). → 사오리 목소리로 할지, 별도 내레이터로 할지 결정 필요. 사오리 목소리라도 .ass Naration 스타일 + narration_styles 등록(립싱크 제외)은 동일.
3. **시리즈 세계관**: 성장 체크리스트 ①은 「같은 아파트 단지·김씨 카메오」. 이 작품은 **일본 상사 배경의 별도 시리즈(#01→#02)**로 보임 → 일본 채널 시리즈로 별도 운영하는지 확인 필요.
4. **#01 자산이 이 저장소에 없음**: 대본이 언급한 Haruna(사오리)·Hideo(미야모토) 목소리 ID, 「#01 유미/오다기리」 관련 파일이 저장소에 없음 → 목소리 ID(엔진·voice_id) 전달 필요.
