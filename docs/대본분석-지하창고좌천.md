### 8-3. 감정별 개선안 (대본 수정안 포함)

#### ① 분노 — 「증인 앞 공개 굴욕」으로 옮기고 1:00 안에 정점
- 씬2 부장실 → **기획부 사무실 한복판**으로 이동. 동료들이 보는 앞에서 곤도가 사오리의 기획서 원본(밤샘 메모 포스트잇이 붙은 것)을 **쓰레기통에 던짐** (무언 인서트 1컷).

#### ③ 도파민 — 「설명」을 「발견」으로 (내레이션 → 화면 연출)
발견 3개를 각각 **3단 쾌감 컷**(손이 멈춤 → 확대 인서트 → 효과음 + 강조 자막)으로:

| 「証拠でもあるのか？」(씬2) | 「…証拠なら、ここに。百二十枚、全部あります」(미야모토가 보관함을 연다) | 사오리 |

- 처벌은 내레이션 대신 **화면으로**: 현수막이 내려짐 / 경비원이 곤도의 사원증을 회수(손 인서트) / 등 돌린 동료들 사이로 연행되는 뒷모습(롱샷) / 바닥에 남은 깨진 와인잔.
- 씬7 보상 추가: 곤도의 빈 책상에서 「常務取締役」 명패 상자를 치우는 인서트, 미야모토 정년 표창장(무지 + 합성 글자).
