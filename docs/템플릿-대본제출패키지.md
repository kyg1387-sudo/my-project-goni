- 제0장 구간표: 후크 0:00~0:20 / 발단 ~3:30(1차 광고) / 전개 ~7:00(2차 광고) / 절정 ~9:30 / 여운 ~10:30. 각 구간 **열린 고리**(30~40초마다 새 질문) 목록.
- 인물 3~5명(일본식 성씨, 가상 회사명 검색 확인), 장소 ≤8, 핵심 소품 1(ECU 대상).

## ④ 대본 본문(일본어 → 한글 검수 번역 병기)
- `docs/대본작성-시스템프롬프트.md` 장르 문체(感動 = です・ます 3인칭 / スカッと = だ・である 1인칭 회고). 시청자 호칭 「皆様」.
- 줄 규격: 한 줄 1호흡·2문장·30자 이하, 「……」 여운, 숫자 한자 + 읽기 위험 어휘 표(제14장 8·제17장 4). 본편에 次回·登録·コメント 줄 금지(제20장 15).
- 줄마다 [화자 / 감정·세기·템포 / 행동] 메모(톤연출표 원천, 제10장 7). 눈물·외침 줄은 VO 설계 표시.
