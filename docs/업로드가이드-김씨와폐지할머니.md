## 1. 본편 업로드 순서 (EP1·EP2와 동일)
1. studio.youtube.com → **만들기 → 동영상 업로드** → 합친 본편 파일 선택
2. **제목**: 아래 제목 A 붙여넣기 (Test & Compare에 A/B/C 모두 등록)
3. **설명**: 아래 한국어 설명 복사
4. **어린이용 아닌가요?** → "아니요, 아동용이 아닙니다"
5. **자세히 보기**: **변경된 콘텐츠(AI 고지) → "예"**, **동영상 언어 → 한국어** (EP1 때 일본어로 잘못 설정됐던 부분 주의)
6. **재생목록**: "김씨 시리즈"에 추가
7. **썸네일**: 3장 업로드 → **테스트 및 비교** 설정
8. **자막 단계**: 언어 **일본어** 추가 → 파일 업로드 → 자막 파일(타이밍 포함) → `kim-cart-grandma.ja.srt`. 한국어도 `kim-cart-grandma.ko.srt` 추가(검색 색인용)
9. **최종 화면**: "동영상에서 가져오기" → EP2 선택 (구독 버튼 + 시청자 맞춤 동영상)
10. **공개 설정 → 예약**: **10-02(금) 19:00** (촉박하면 10-03(토) 19:00)
11. 게시 후: 아래 **고정 댓글** 달기
