# 『引きこもりの息子』(hikikomori-ja) 실증 보강 기록

## PHASE 1 (2026-10-27)

1. **자동 언어 검사 「문제 0」 ≠ 오독 0**: 97줄 본녹음에서 자동 검사는 문제 0건이었지만, Whisper 전사를 줄마다 육안 대조해 오독·뭉개짐 4줄을 찾았다
   (line006 値下げ→「目下げ」, line011 だそうよ→「がそうよ」, line068 瀬尾社長→「背負う社長」, line077 瀬尾精工と→「小生高等」).
   → 본녹음 검수는 **전사 전수 대조**를 필수로 한다(동음이의 표기 차이 — 精工/成功, 意向書/移行書 — 는 합격).
2. **고유명사는 가나 입력도 흔들린다 → 3안 비교**: 「鳳凰工業」은 가나(ほうおうこうぎょう) 입력에서 「法工業」(お 탈락), 쉼표 삽입 시 「方を工業」, 한자 입력 시 「包合工業」.
   가타카나(ホウオウ工業)만 정확. 한 번 흔들린 고유명사는 가나·한자·가타카나 3안을 한 번에 만들어 단독 폴더 언어 검사로 고른다(`scripts/auditions/hikikomori-na3.json`).
   느린 템포(0.9 이하)의 짧은 「성+社長」(せお社長→「背負う」)도 가타카나 성이 안정.
3. **줄 추가(길이·광고 지점 보강) 때 기존 녹음은 번호만 재배치**: line###은 시간 순서라 줄을 끼우면 번호가 밀린다. 태그 기준으로 기존 파일을 새 번호로 `git mv`(2단계 이름 변경)하면
   오디션 잡의 「기존 파일 재사용」으로 새 줄만 과금된다(92줄 재사용 + 5줄 신규). 진행 중인 언어 검사는 번호가 바뀌기 전 것이므로 취소 후 재실행.
4. **실존 기업 검색은 가족 성 + 업종까지**: 「加藤精工」은 대본 속 업종(자동차 부품)과 같은 실존 기업이었다. 독일 연구소 「ケスラー」는 미국 재활 재단의 모빌리티 연구 부문과 겹쳤다.
   회사명 검색은 「이름 + 업종」으로, 외국 기관명은 영어 철자로도 검색한다.

5. **「……」 정적 실측(2026-10-29)**: 본녹음 43줄의 「……」 안쪽 정적 평균 0.37초·최소 0.15초, 줄 앞·끝 「……」는 정적 0(발화 구간 측정에서 잘림). 발성 디렉션 「쉼표·말줄임표 0.5~0.8초 정적」에 미달 →
   `productions/hikikomori-ja/pace_pauses.py`로 여운 16줄만 0.6초(최대 0.8)로 확장(+6.2초). 0.2초 미만 정적은 촉음·파열음 폐쇄일 수 있어 제외. Lock 10:30→10:36, 2차 광고 6:57→7:01.
6. **절제된 오열 A/B**: 오열 3줄(L26·L40·L61)을 whisper 1.0 / sad 0.6로 추가 생성해 현재(sad 1.0)와 비교 청취(`hikikomori-restrained.json`). 소리 내 우는 연기는 OmniHuman에서 웃음으로 바뀌는 위험(제18장 4)도 있어 절제 쪽이 립싱크에도 유리.
8. **아웃트로 진행자 스타일링(2026-10-29)**: 아웃트로 컷마다 헤어·의상·액세서리를 예쁘게 정돈해 지정, 작품마다 새 스타일, 한 아웃트로 안에서는 같은 스타일 유지(컷 사이 의상 불일치 방지). CLAUDE.md 제19장 8.
