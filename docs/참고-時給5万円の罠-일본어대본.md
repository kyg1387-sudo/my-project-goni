# 『時給5万円の罠』 일본어 정제 대본 (고니감독님 첨부 대본 → 구어체 일본어, 구조 유지)

요청(2026-10-19): 「1인칭 몰입 → 탐욕 자극 → 극대화된 공포·서스펜스 → 합법적이고 통쾌한 반전」 구조를 그대로 두고,
번역투 없이 일본 현지 구어체로 짧고 강하게 번역·정제한다.

**원본에서 바꾼 것 3가지 (구조는 그대로)**
1. **플롯 모순 수정**: 원본은 켄타가 「욕심에 끌려 지원」했는데 결말에서 「경찰이 심어 둔 함정 수사의 일환」이 되어 앞뒤가 맞지 않았다.
   → 출발 전날 켄타가 불안해서 경찰 상담 창구(#9110)에 전화했고, 수사 중이던 경찰이 협조를 요청하며 발신기를 건넸다는 설정으로 바꿨다.
   2장에서 복선 한 줄(「念のため、ある番号に電話をかけていました」)을 깔고 4장에서 회수한다.
2. **실재 기관명 완화**: 「警視庁 サイバー犯罪対策課」 같은 특정 부서명 대신 「警察」「捜査員」으로 쓰고, 맨 끝에 フィクション 표기를 넣었다(오해 유발 정책 대비).
3. **길이**: 11:30 → 약 10:30(문장 압축). 내레이션은 1문장 30자 이하, 한 줄 1~2문장(제14장 8).

TTS 읽기 주의: 五万円(ごまんえん)·四時間(よじかん)·一週間(いっしゅうかん)·三か月(さんかげつ)·#9110(きゅういちいちまる)·闇バイト(やみバイト).

## 第1章 導入（0:00〜1:20）— 離脱防止フック

［画面］暗転。スマホの通知音が三回。赤い文字「時給 50,000円」が点滅。

```
時給、五万円。
資格はいりません。面接もありません。
スマホを数回タップするだけ。報酬は、その日に現金で。
都内近郊。たった四時間の、簡単な夜間作業。
……あなたなら、断れますか？
```
（※시청자 직접 호칭은 원본의 몰입 장치라 이 1회만 남김. 채널 美談 작품에서는 「皆様」 규칙 적용）

```
この求人に応募した、二十代の青年。ケンタさん（仮名）。
応募から、わずか一週間。
彼は、連絡が取れなくなりました。
最後にスマホの電波が確認されたのは、都内郊外の物流倉庫。
ところが、その倉庫に、彼が入った記録は……どこにもありませんでした。
今、日本中で若者が狙われている「闇バイト」。
今日は、その一番深い闇の中へ、ご案内します。
```

## 第2章 展開（1:20〜3:40）— 欲望を刺激し、仕組みを暴く

［画面］ネオンの新宿。カメラがゆっくり、裏路地の古いマンション地下へ。

```
入口は、ごく普通の求人サイトでした。
仕事内容は「倉庫の資材整理と、在庫の廃棄」。
どこから見ても、まともなアルバイトです。
ただ、条件だけが、妙に厳しかった。
ひとつ。スマホと電子機器は、すべて持ち込み禁止。
ふたつ。移動中は、必ずアイマスクをつけること。
みっつ。口外すれば、家族にも責任を取らせる。そんな誓約書へのサイン。
……おかしい。誰が見ても、おかしい。
でも、五万円は、人の疑う力を鈍らせます。
ケンタさんも、こう思いました。
「まさか、犯罪ってことはないだろ。カメラさえ持っていかなきゃ、大丈夫」
ただ、出発の前の晩。
胸騒ぎが消えなかった彼は、念のため、ある番号に電話をかけていました。
（間）
そして、ここからが、蜘蛛の巣の入り口でした。
```

## 第3章 クライマックス（3:40〜7:20）— 恐怖とサスペンス（離脱防衛区間）

［画面］粗いCCTV質感。懐中電灯ひとつで地下倉庫を照らす一人称ショット。低周波のBGMが高まる。

```
約束の深夜。
黒いワンボックスカーに乗せられ、アイマスクを外された場所。
そこは、地下深くに打ち捨てられた、巨大な施設でした。
待っていたのは、古い家具でも、廃材でもありません。
床に、無造作に積まれていたもの。
誰かの免許証。財布。
そして、持ち主の消えたスマホが、何百台も。
（間）
その瞬間、ケンタさんは気づきます。
これは、片付けの仕事なんかじゃない。
行方の分からなくなった人たちの、最後の痕跡を消す仕事。
その身分を使って、金をだまし取る組織の、証拠隠滅の現場だったんです。
振り返って、逃げようとしました。
でも、鉄の扉は、もう閉まっていました。
倉庫の奥。暗がりの中に、人影が見えます。
先に連れてこられた若者たちが、うつむいたまま、黙々と手を動かしていました。
「俺も……ここで、消されるのか？」
息が、うまく吸えない。
心臓の音だけが、やけに大きく聞こえていました。
```

## 第4章 反転・スカッと結末（7:20〜9:40）— 反撃と断罪

［画面］緊張の頂点で画面が白く飛ぶ。警察無線。鉄扉が破られる衝撃音。

```
……でも、ここで終わりではありませんでした。
見張りの男たちが気を抜いた、その一瞬。
ケンタさんは、襟の裏に縫い込んでいた小さな発信機の、スイッチを押しました。
覚えていますか？　出発の前の晩、彼がかけた一本の電話。
相手は、警察の相談窓口でした。
実はこの組織、三か月も前から、警察が追い続けていた相手だったんです。
「中に入る人がいるなら、協力してほしい」
ケンタさんは、怖さを押し殺して、うなずいていました。
（間）
「警察だ！　全員、動くな！」
鉄の扉が破られ、何十人もの捜査員が、ライトを照らしてなだれ込みます。
若者たちを使い捨ててきた男たちの顔が、一瞬で、ひきつりました。
次々と手錠がかけられ、連れ出されていく男たち。
翌朝、このニュースは全国を駆けめぐりました。
組織は、跡形もなく、崩れ去ったのです。
```

## 第5章 アウトロ（9:40〜10:30）— 余韻と登録誘導

［画面］温かく落ち着いたBGMへ。チャンネルロゴ、登録・高評価ボタンのアニメーション。

```
時給五万円という、甘い言葉。
その裏には、人の人生ごと奪おうとする、大きな悪意が隠れています。
楽に稼げる話なんて、ありません。
もし、身近な人がそんな求人を見ていたら……どうか、一言、声をかけてあげてください。
迷ったときは、警察の相談窓口「#9110」へ。
このお話が心に残ったら、チャンネル登録と高評価をお願いします。
次回も、日本の知られざる真実をお届けします。
ご覧いただき、ありがとうございました。
```

［画面下・小さく］この物語は、実際の事件をもとに再構成したフィクションです。登場する人物・団体は架空のものです。
