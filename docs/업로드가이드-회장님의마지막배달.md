## 3) 국가별 반응 확인하는 법 + 다음 언어 판단 기준

- 유튜브 스튜디오 → [분석] → [시청자층] → 아래로 내려 **상위 지역** 확인

  다음 작품도 일본어 기본 + 이번 작품에 **영어 자막** 추가를 검토
- 특정 국가에서 평균 시청 지속시간이 한국보다 길게 나오면 그 언어를 우선 확장
