# EP5 「김씨가 사라진 날」 대본 v2 (감동 강화판 — 사용자 확정 대기)

김씨 시리즈 5편 · 본편 약 5:32(장면 합계 332초 — v1과 막별 시간까지 동일) + 공통 아웃트로 8초 · 계절: 한겨울 1월

## 로그라인
십 년 동안 하루도 자리를 비운 적 없던 경비원 김씨가 무단결근한다. 그제야 주민들은
그에 대해 아무것도 모른다는 걸 깨닫는다. 응급실 보호자 칸은 비어 있었고, 휴대폰에
저장된 번호는 '여보' 하나 — 칠 년 전 세상을 떠난 아내의 번호뿐이었다.
