# 제작 규격 보강 — 조명·카메라 앵글·편집 구현 기법 (2026-10-04 사용자 확정)

CLAUDE.md 제3장(렌즈·조명·전환)을 실전용으로 보강한다. 요약은 CLAUDE.md 제8장, 상세는 이 문서다.
근거: 사용자가 제공한 「일본 감동 드라마 조명·카메라 가이드」(고레에다 히로카즈·이와이 슌지 풍 정적 정취 + 스카토 긴장), 사용자 지시 「카메라 각도를 다양하게」, 김씨 시리즈 EP1~EP4의 AI 생성 한계 실증.
첫 적용: 『柳の葉と一杯の水』(`productions/willow-leaf-ja/02_카메라앵글설계.md`).

## 1. 구간별 조명 설계

| 구간 | 조명 | 키프레임 프롬프트 문구 (감독 이름 대신 묘사어 — 이름은 모델이 무시하거나 엉뚱하게 해석) |
|---|---|---|
| 일상·회상·눈물 | 디퓨즈 자연광 + 골든아워 역광 림라이트, 대비 낮게, 3200K 계열 | `soft natural diffused light, low warm golden-hour backlight, glowing rim light on hair and shoulders, gentle contrast, lifted shadows` |
| 창가·실내 정적 장면 | 얇은 커튼·잎 사이로 부서지는 산란광 | `daylight diffused through a thin white curtain`, `dappled light through leaves` |
| 압박·갑질 (사무실 등) | 위에서 수직으로 떨어지는 차가운 형광등 5600K 이상, 눈가·턱 밑 그늘 | `single cold fluorescent tube directly overhead, hard top light, dark shadows under the brows and chin, faint cyan cast` |
| 대면·권력 등장 | 강한 역광 실루엣, 실내는 어둡게 | `intense white daylight blasting through the doorway behind him, silhouette, strong backlight, darker interior` |
| 회상(수십 년 전) | 세피아·비네팅 | `desaturated sepia, soft vignette, dust in the air` |

- 규격 제3장의 Chiaroscuro(강한 명암)는 **압박·대면 구간에만** 쓴다. 일상·감동 구간은 부드러운 자연광으로 대비를 낮춘다.
- 조명은 **로케이션 시트 단계에서 잠근다**. 사무실 시트가 톱라이트여야 그 장소의 키프레임이 모두 따라온다. 키프레임에서만 바꾸면 컷마다 어긋난다.

## 2. 앵글 규칙 (모든 컷)

| # | 규칙 | 기준 |
|---|---|---|
| A1 | 연속 두 컷 같은 구도 금지 | 앞 컷과 사이즈 2단계 이상 또는 각도 30° 이상 차이 |
| A2 | 180° 축 고정 | 대화는 두 인물을 잇는 가상선 한쪽에서만. 축을 넘을 때는 인서트·중립 컷을 한 컷 거친다 |
| A3 | 장면 문법 | 설정 와이드 → 미디엄 → CU로 들어가고, 감정 정점 뒤에는 와이드나 인서트로 여운. 후크·충격 컷은 CU부터 가능 |
| A4 | 앵글의 의미 고정 | 하이 = 무력·감시 / 로우 = 권력·위압 / 아이레벨 = 공감 / 오버헤드 = 운명·전모 / 더치 = 붕괴 |
| A5 | 권력 반전은 앵글로 | 전반에는 가해자를 로우·피해자를 하이로, 반전 후에는 뒤집는다. 같은 장소에서 앵글만 바꿔 힘의 이동을 보여 준다 |
| A6 | 렌즈 4단 | 24mm 와이드(공간·위압) / 35mm 상황 / 50mm 대화 / 85mm 감정 CU / 100mm 매크로 인서트 |
| A7 | 전경 프레이밍 | 장면마다 최소 1컷은 유리문·나뭇가지·진열대·커튼 **너머로** 엿보는 구도 (관찰자 시점의 정적 정취) |
| A8 | 시각 환기 | 정지성 컷 5초 초과 금지(제4장). 3~5초마다 사이즈·앵글·인서트 전환 |
| A9 | 왜곡 기법은 각 1회 | 돌리줌·더치는 작품당 한 번씩, 서로 다른 순간에. 겹치면 충격이 흐려진다 |
| A10 | 악역 근접 CU 금지 | 악역 얼굴은 가슴 위 거리까지만. 긴장은 손·땀·안경·입술 ECU 인서트로 |
| A11 | 초커는 감정 정점에만 | 주인공·조력자의 눈물·결심 순간에 한정 |

## 3. AI 생성의 앵글 한계와 대응 (김씨 시리즈 실증)

| 한계 | 대응 |
|---|---|
| OmniHuman 대사 CU는 정면~45°까지만 안정, 측면 대사는 입이 뭉개짐 | 대사 CU는 정면·3/4. 측면·뒷모습은 입이 안 보이는 대사 처리에만 |
| 롱샷은 얼굴 동일성이 약함 (EP3 S26) | 와이드의 인물은 실루엣·뒷모습. 얼굴로 누구인지 알아봐야 하면 미디엄 이상 |
| i2v 고개 회전 20° 초과 시 얼굴 변형 | 돌아보는 동작은 컷을 나눈다 (앞 컷 끝 / 다음 컷 시작) |
| i2v는 줌·초점·카메라 회전 지시를 무시 (EP4 S52) | 아래 4장처럼 **편집에서 구현** |
| 장소 시트에 없는 시점은 배경이 어긋남 | 컷의 60% 이상을 차지하는 주 무대는 **앵글 시트**(역방향·하이·로우·전경 너머)를 PHASE 2에서 추가 |
| 키프레임에 감정이 없으면 i2v가 표정을 못 만듦 | 앵글과 함께 표정 50~70%를 키프레임에 미리 반영 (제2장 3) |

## 4. 편집에서 구현하는 카메라 기법 (모두 로컬, 무료)

| 기법 | 구현 | 쓰임 |
|---|---|---|
| 슬로우 푸시인 / 풀백 | 고해상도 키프레임에서 zoompan (확대 → 원래, 원래 → 확대) | 단죄 대사, 엔딩 드론 풀백 대용 |
| 돌리줌 | 키프레임에서 인물 마스크를 분리(배경 제거 모델, CPU) → 인물 크기 고정 + 배경만 확대·원근 늘림 → 2.5D 합성. 5초 클립을 70% 속도로 | 정체 발각 1회 |
| 랙 포커스 | 같은 구도에서 초점이 다른 키프레임 2장(EDIT_FROM) → 0.8초 블러 디졸브 | 소품 → 인물 눈, 어깨 → 인물 |
| 더치 앵글 | 클립을 5~10° 회전 + 크롭 | 비리 발각 1회 |
| 핸드헬드 | 저주파 미세 흔들림(위치 ±0.6%, 회전 ±0.3°) | 악역이 무너지는 순간. 립싱크 컷에는 쓰지 않는다 |
| 색감 통일 | 전 컷 공통 그레이딩 + 필름 그레인 | pro(1080p)·lite(720p) 혼합 소스를 한 영화처럼 |

## 5. 작품별 산출물 (PHASE 3 입력)

1. **카메라 앵글 설계표**(`productions/<작품>/02_카메라앵글설계.md`): 장면마다 컷 순서를 `사이즈·앵글·렌즈·무빙·전경` 표기로 쓴다. OMNI 대사 컷은 대본 촬영 지정표와 일치시킨다.
2. **PHASE 3 생성기 자동 검사**: A1(연속 같은 구도), A2(축 위반), A9(왜곡 기법 2회 이상), OMNI 컷의 각도(측면 금지)를 위반하면 빌드를 멈춘다.
3. **PHASE 4 보고**: 키프레임 검수 때 장면별 앵글 분포(EL/HA/LA/OH 비율)를 함께 보고한다. 한 앵글이 60%를 넘으면 다시 설계한다.
