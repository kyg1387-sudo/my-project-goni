## 1. 프롬프트 5단 공식 (고니감독님 제안·확정 2026-10-12)
- 제안 원문: 「[카메라 앵글 및 무빙] + [주인공 및 인그리디언트(@)] + [행동 및 표정] + [배경 및 조명] + [오디오/대사 지시]」(Veo 3 계열 한 문장 생성 문법).
- 검토 결과(채택/불채택):

| 요소 | 우리 규격 | 판정 |
|---|---|---|
| 카메라 앵글·무빙 | PHASE 3 샷 리스트. i2v는 무빙 지시를 무시 → 편집 구현(제8장 6) | 순서·구도는 채택, 「tracking camera」류 생성 지시는 불채택 |
| @인물 | PHASE 2 시트 + IDENTITY FIRST 기준 얼굴(제11장 2) | 채택(동일 개념) |
| 행동·표정 | 큰 동작 금지(제2장 3), 표정은 키프레임에 50% 반영 | 소동작으로 채택 |
| 배경·조명 | 로케이션 시트 잠금(제8장 1) | 채택 |
| 오디오·대사 | Typecast 배역 음성 → OmniHuman, 효과음 별도 믹스(제11장 19·22) | **불채택**(음성 일관성·일본어 억양 검수·대본 동결·광고 지점 설계와 충돌, t2v 금지, 단가 4~7배) |

- 구현: `scripts/prompt_format.py`(compose_keyframe / compose_motion / split_sections / check_order / check_motion).
  - `build_chika_phase3.py`: keyframe_prompt를 PRESET → [CAMERA] 앵글·렌즈·구도 → [CHARACTER] → [ACTION] 장면 문장 → [SETTING] 조명·표기·PLAIN → [NEGATIVE]로 조립. i2v 프롬프트는 [CAMERA] 고정 → [CHARACTER] 유지 → [ACTION] 소동작 → [LOCK] 금지 동작.
  - `build_chika_keyframes.py` `build()`: 기존 `insert(1)` 누적(순서가 뒤집힘) → 5단 버킷. PHASE 3의 라벨 프롬프트는 `split_sections`로 같은 버킷에 합친다(라벨 중첩 방지).
  - #03 생성기는 이 두 파일을 복사해 쓴다(제7장 1).
- 검증(2026-10-12): #02 전체(157컷) 재생성 시 순서 위반 0, 큰 동작·오디오 경고 0. 첫 검사에서 「foam running over」「the aisle runs along」이 「run」으로 오탐 → 사람 주어일 때만 검사하도록 수정.
- #02 산출물은 바꾸지 않았다(완성·업로드 예약 완료). 새 순서는 #03 PHASE 3부터 적용.
