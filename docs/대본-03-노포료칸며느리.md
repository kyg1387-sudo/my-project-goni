## 0. 개정 요약 (1차 대본 대비)

| # | 결함 | 개정 |
|---|---|---|
| 1 | 썸네일 답변 「では、どうぞ代わりの方と」가 본편에 없음 | 씬6 마이의 구직 전화에서 와카나의 대사로 회수 (컷 44) |
| 2 | 예약 70% vs 매출 40% 숫자 충돌 | 전부 **四割(40%)** 로 통일 (콜드오픈·씬5) |
| 3 | 제목 "繁忙期の前日" vs 본문 "1주일 뒤" | 씬4 내레이션 「繁忙期まで、あと三日」, 씬5 「繁忙期、初日」로 정합 |
| 4 | 남편 다카유키 결말 없음 | 씬6 「夫からの電話には一度も出なかった」 + 씬7 통화에 끼어드는 남편 (컷 49) |
| 5 | 콜드오픈 40초, 모욕 대사가 늦음 | 25초로 압축, 모욕 대사를 0:03에 배치 |
| 6 | 씬2 내레이션만 110초 | 70초로 압축, 「家族なんだから当然」을 도미코의 실제 대사로, 남편 장면을 중간에 삽입 |
| 7 | 결정 전의 "싸늘한 미소"가 주인공을 계산적으로 보이게 함 | 미소를 도미코의 「出て行けばいい」 직후 "해방된 표정"으로 이동 |
| 8 | 「は?」 한 음절, 「ｗ」 TTS 오독 | 「はあ?」 + 연기 태그 [sneering] |
| 9 | 손님 빼가기(引き抜き) 오해 | 씬6 「私からは、何も言っていない」 명시 |
| 10 | 씬5→6 열린 고리 없음 | 씬5 끝 「そしてその頃、私は――」 |
| 11 | 천(陳)의 전화 = 초상 1장 추가 비용 | 타이베이 사무실 **뒷모습 컷**으로 처리(얼굴 없음 → 초상 불필요, 화자-화면 일치 유지) |

| 13 | CTA 뒤 참여 유도·다음 화 예고 없음 | 질문 자막 + 아웃트로 8초 추가 |

## 1. 제목 · 썸네일 · 설명 (일본어)

**제목 (전반 30자 안에 모욕 인용이 들어가도록 순서 고정)**
【スカッと】「よそ者の嫁は裏方で十分」老舗旅館で私を無給の下働き扱いした義母と義姉。繁忙期の三日前、私が静かに旅館を去った結果…

**썸네일 문구 (2단, 큰 글씨)**
上: 「あんたの代わりなんていくらでもいる」
下: 「では、どうぞ代わりの方と」

**썸네일 그림**: 상단은 마이의 비웃는 얼굴(컷 16 프레임), 하단은 하나이카다 프런트의 와카나 미소(컷 44 프레임, 자막 없는 순간 추출).
A/B 2종: ② 상단을 도미코의 애원 얼굴(컷 48)로 교체.

**고정 댓글 질문**: 「あなたが若菜なら、月見荘に戻りますか? コメントで教えてください」

## 4. 본편 (씬 · 컷 · 대사 · 내레이션)

표기: **N** = 내레이션(와카나 1인칭, 회상 톤), 대사는 「 」, 한국어 해석은 → 뒤.
[카메라] = Movement / Angle / Size / 길이. 전환 = 규칙 8-1(리액션 여운·디졸브·소리 브리지).
대사 컷은 "가슴 위 클로즈업, 손 미포함"을 기본 구도로 한다(EP2 교훈 ⑪).

### 씬1 콜드오픈 (0:00~0:25)

**컷1** (3s) 쓰키미소 현관. 단골들 앞에서 새 기모노의 마이가 우아하게 절한다. 도미코가 옆에서 손을 펴 소개.
[카메라] Static / Eye-level / Medium full 투샷(도미코·마이) / 3s

**컷2** (7s) 도미코, 단골들에게. 말끝에 시선만 복도 끝으로 흘린다.
富子「皆さま、こちらが当館の若女将、娘の麻衣でございます。……あちらは、下働きの者ですので、お気になさらず」
→ "여러분, 이쪽이 저희 료칸의 젊은 안주인, 제 딸 마이입니다. ……저쪽은 허드렛일하는 사람이니 신경 쓰지 마세요."
[카메라] Slow zoom in, camera locked / Eye-level / Medium close-up 단독 / 7s / End: 시선 돌리는 순간 홀드 1초

**컷3** (5s) 복도 끝, 앞치마 차림의 와카나가 무릎을 꿇고 걸레질. 고개를 들지 않는다.
[카메라] Rack focus 전경(단골들의 어깨)→후경(와카나) / Eye-level / Long shot / 5s
N1 下働き。それが、嫁いで五年になる私の肩書きだった。
→ 허드렛일하는 사람. 그게 시집온 지 5년 된 나의 직함이었다.

**컷4** (6s) 와카나의 손이 걸레를 쥔 채 멈춘다. 손 인서트 → 천천히 얼굴로.
[카메라] Slow dolly in / High angle / Close-up(손→얼굴) / 6s / End: 눈을 든 순간 홀드 1초
N2 でも二人は、まだ知らなかった。この旅館の売り上げの四割を動かしていたのが誰で――その人がいなくなった時、百年の暖簾に何が起きるのかを。
→ 하지만 두 사람은 아직 몰랐다. 이 료칸 매출의 40%를 움직이던 사람이 누구인지, 그 사람이 사라졌을 때 100년의 노렌(가게 간판)에 무슨 일이 일어날지.

**컷5** (4s) 타이틀 카드 「老舗旅館の嫁」 — 검은 배경, 명조체(편집에서 얹음). 샤미센 한 음 + 물소리 브리지.
전환: 컷4 → 타이틀 디졸브 0.5초.

### 씬2 무급 노동 (0:25~1:35)

**컷6** (5s) 새벽 4시, 어두운 주방. 와카나가 불을 켜고 가마솥 뚜껑을 연다. 김이 오른다.
[카메라] Static / Eye-level / Medium / 5s
N3 私は若菜、三十三歳。東京の外資系ホテルで働いていた頃、お客として来ていた隆之さんと出会い、この温泉街の老舗旅館「月見荘」に嫁いだ。
→ 나는 와카나, 33세. 도쿄의 외국계 호텔에서 일하던 시절, 손님으로 온 다카유키 씨를 만나 이 온천가의 노포 료칸 '쓰키미소'로 시집왔다.

**컷7** (5s) 낮, 사무실. 노트북 앞의 와카나. 화면은 보이지 않는 각도(글자 회피). 전화기를 어깨에 끼고 메모.
[카메라] Side tracking 느리게 / Eye-level / Medium close-up / 5s
N4 朝は四時に起きて、朝食の仕込み。昼は予約サイトの管理と、海外からのお客様の対応。英語と中国語ができるのは、この旅館で私だけだった。
→ 새벽 4시에 일어나 조식 준비. 낮에는 예약사이트 관리와 해외 손님 응대. 영어와 중국어를 할 줄 아는 건 이 료칸에서 나뿐이었다.

**컷8** (6s) 현관. 서양인 가족에게 영어로 안내하는 와카나(입 모양만, 대사 없음 — 무언 Action). 가족이 웃는다.
[카메라] Arc 90도 / Eye-level / Medium full / 6s
N5 海外の旅行会社との契約を一から作り、外国人のお客様は五年で十倍になった。
→ 해외 여행사와의 계약을 처음부터 만들었고, 외국인 손님은 5년 만에 10배가 되었다.

**컷9** (7s) 주방 뒷문. 도미코가 와카나에게 봉투 대신 빈손을 내보이며.
富子「お給料? 家族なんだから、当然でしょう。麻衣は別よ。あの子は外で働いていたんだから」
→ "월급? 가족이니까 당연하잖아. 마이는 달라. 걔는 밖에서 일했던 애니까."
[카메라] Static / Eye-level / Medium close-up 단독 / 7s / End: 등을 돌리는 순간 홀드 1초

**컷10** (4s) 리액션. 와카나, 아무 말 없이 고개를 숙인다. 손에 든 식칼을 도마에 조용히 놓는다.
[카메라] Static / High angle / Close-up / 4s
N6 嫁いで五年。私の給料は、一円もなかった。
→ 시집온 지 5년. 내 월급은 1엔도 없었다.

**컷11** (6s) 밤, 부부의 방. 다카유키는 이불 위에서 휴대폰 게임. 와카나가 옆에 앉는다.
若菜「隆之さん。……せめて、お義姉さんと同じように、お給料を」
→ "다카유키 씨. ……적어도 형님처럼 월급을."
[카메라] Static / Eye-level / Medium close-up 단독(와카나) / 6s

**컷12** (7s) 다카유키, 화면에서 눈을 떼지 않는다.
隆之「母さんに逆らうなよ。お前はうちの嫁なんだから、黙って手伝ってればいいんだって」
→ "엄마한테 대들지 마. 넌 우리 집 며느리니까 그냥 조용히 돕고 있으면 되는 거야."
[카메라] Static / Eye-level / Medium close-up 단독(다카유키, 휴대폰 불빛 아래) / 7s / End: 홀드 1초

**컷13** (5s) 밤 11시, 사무실. 장부를 덮고 스탠드를 끄는 와카나. 어둠.
[카메라] Static / Eye-level / Medium / 5s
N7 夜十一時、帳簿を閉じる。それが、私の一日だった。
→ 밤 11시, 장부를 덮는다. 그게 나의 하루였다.
전환: 스탠드 꺼짐 → 암전 → 씬3 디졸브(현장음 풍경 소리 브리지).

### 씬3 가족회의 · 결정 (1:35~3:50)

**컷14** (5s) 낮, 좌시키. 도미코 상석, 마이 옆, 다카유키 구석, 와카나는 문가 말석. 설정샷.
[카메라] Static / High angle / Long shot(4인) / 5s

**컷15** (8s) 도미코, 찻잔을 내려놓으며.
富子「来月から、予約もお客様の対応も、全部麻衣に任せます。若菜さん、あなたは厨房と掃除だけでいいわ」
→ "다음 달부터 예약도 손님 응대도 전부 마이에게 맡길 거예요. 와카나 씨, 당신은 주방이랑 청소만 하면 돼요."
[카메라] Slow dolly in / Eye-level / Medium close-up 단독 / 8s

**컷16** (6s) 와카나, 조심스럽게.
若菜「でも……海外の旅行会社とのやり取りは、私でないと――」
→ "하지만…… 해외 여행사와의 연락은 제가 아니면――"
[카메라] Static / Eye-level / Medium close-up 단독 / 6s

**컷17** (9s) 마이, 코웃음. 부채를 펴며.
麻衣「はあ? 英語なんて、翻訳アプリで十分でしょ。よそ者の嫁は裏方で十分なのよ。あんたの代わりなんて、いくらでもいるんだから」
→ "하아? 영어 같은 건 번역 앱이면 충분하잖아. 외부인 며느리는 뒤에서 일이나 하면 돼. 너 대신할 사람은 얼마든지 있으니까."
[카메라] Slow zoom in, camera locked / Low angle(약간) / Medium close-up 단독 / 9s / End: 홀드 1초
※ 썸네일 상단 프레임. 와카나는 이 컷에서 **고개를 숙인 채 무표정** (미소 없음 — 공감 유지).

**컷18** (4s) 리액션. 다카유키가 고개를 숙이고 찻잔만 본다. 무언.

## 7. 제작 적용 메모

- **언어**: 오디오 설정 `language_boost: "Japanese"`, 언어 QA 기준도 일본어(외국어 섞임 0건).
- **엔진 배정(확정)**: 전 배역 ElevenLabs v3 일본어. 내레이션·와카나 = 같은 목소리(1인칭 회상),
  도미코·마이·다카유키·사쿠라이·천·단골 = EL 보이스 라이브러리에서 일본어 네이티브 후보 2~3개씩
  시험 생성 → 사용자 청취 선정. MiniMax는 EL 키가 없을 때의 폴백 전용(음색 흔들림, EP2 교훈 ⑨).
  대본 총 TTS 분량 약 1,900자 → EL 과금 기준으로 전편 1회 생성 약 2,000자, 재생성 10회를 잡아도
  2만 자 이내(Starter 월 $5 플랜 3만 자 안에서 해결). 파이프라인에 EL TTS 경로가 아직 없으므로
  `generate_audio.py`에 `tts_engine: "elevenlabs"` + GitHub Secret `ELEVENLABS_API_KEY` 추가 작업이 선행된다.
- **립싱크 대상 컷** (가슴 위 클로즈업·손 미포함 설계): 2, 9, 11, 12, 15, 16, 17, 19, 21, 24, 30, 31, 34, 41, 43, 44, 48, 49, 50 (19컷). 컷33·35(천 뒷모습)는 립싱크 제외.
- **무인 컷** 22, 28, 38, 46: 프롬프트에 "사람이 한 명도 없는, 인물 없음" 이중 명시.
- **글자 회피**: 노렌·명패·장부·휴대폰 화면·파일 표지 전부 무지. 실제 문구는 자막 카드. 컷29는 생성 안 함.
- **의상 연속성**: 와카나는 씬1~3 앞치마+감색 작업복, 씬6~7 연남색 기모노 → 초상 2종. 마이의 새 기모노는 씬1·3·6 동일.
- **소품 연속성**: 인수인계서 파일(컷22→23→24→28) 같은 무지 남색 표지로 4컷 모두 명시.
- **BGM**: bgm_segments 3곡 — 도입(샤미센·고토, 차분), 중반(현악 긴장, 씬4~5), 결말(피아노, 해방감). 곡 사이 페이드아웃 → 2초 숨 → 페이드인.
- **일본어 자막 .ass + 한국어 .srt** 둘 다 산출(한국 채널 CC용 한국어, 본편 자막은 일본어).
