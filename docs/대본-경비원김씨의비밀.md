# 경비원 김씨의 비밀 (확정 대본 · 2고)

작품 3 · 약 10분 · 감동 단편 드라마 · 채널 미담이야기
사용자 확정: 2026-09-20 (감동 강화판 승인)

## 로그라인
아파트 주민들이 무뚝뚝한 경비원의 해고 서명을 받는다. 해고 사유는
"밤마다 아이 뒤를 밟는 수상한 남자" — 그러나 그것은 7년 전 세상을 떠난
아내와의 약속을 지키던, 말없는 사랑이었다.

## 등장인물 (4명 + 무언 단역)
- **김영곤** (68) — 아파트 경비원. 무뚝뚝, 말수 없음. 명찰 "김영곤".
  감독 본인 얼굴(정면 사진 → 기준 초상) + 본인 ElevenLabs 보이스(8vwSOQHQApfVx993mKf9). 주연.
- **박여사** (55) — 입주민 대표. 깐깐하지만 악인 아님. MiniMax 오디션.
- **지우** (10, 여아) — 1203호. 밤늦게 학원에서 혼자 귀가. ElevenLabs 아동 보이스(민호 방식: 도서관 보이스 + 아이 연기 태그 + 음높이 보정).
- **지우 엄마** (38) — 맞벌이. 민원인(핵심 반전). MiniMax 오디션.
- 폐지 할머니, 관리소장 — 무언 단역.

상징 소품: 아내의 **꽃무늬 수첩** · **명찰 "김영곤"** (본편 전 글자 유지 시험 1장면 필수)

## 눈물 포인트 5개 구조
1. 해고 통보일, 명찰을 풀어 내려놓는 손 (S15)
2. 해고된 날 폭설 속에 지우를 데리러 오는 김씨 (S18)
3. 눈길을 돌아가는 김씨의 뒷모습 + 지우 엄마의 흔들리는 눈 (S21)
4. "내가 신고한 그 사람이…" 지우 엄마의 오열 (S26)
5. 아내의 유언 — "밤길에 애들 좀 봐줘요" (S29~S30)

## 1막 — 수상한 남자 (0:30~2:10)

- S1 (자막 카드) 「사흘 전」 — 아파트 단지의 평온한 아침 전경.
- S2 무언: 인사해도 고개만 까딱하는 김씨. 무표정.
- S3 박여사: "아니, 좀 웃으면서 주시면 어디 덧나요?" / 김씨: "…택배요, 1502호."
- S4 놀이터 앞, 주민들 수군거림. 박여사(굳은 얼굴로 서명지를 꺼내며):
  "세상에… 애들 다니는 단지에서…! 이건 그냥 넘어갈 일이 아니에요!"

## 2막 — 김씨의 밤 (2:10~4:20) — 무언 장면 중심

- S9 무언: S4와 같은 구도, 따뜻한 조명 — 지우 열 걸음 뒤의 김씨 (같은 장면, 다른 진실).
- S10 무언: 지우가 미끄러질 뻔한 빙판길 → 이튿날 새벽 그 자리에 소금 뿌리는 김씨.
- S11 무언: 지우네 현관 불이 켜질 때까지 화단 옆에 서 있는 김씨. 하얀 입김.
- S12 무언: 경비실, 꽃무늬 수첩에 기록. 갈피의 오래된 사진을 쓸어보는 손 (내용 미공개 — 복선).
- S13 무언: 폐지 리어카 언덕길을 말없이 밀어주고 먼저 걸어가는 김씨.

## 3막 — 폭설의 밤 (4:20~6:20)

- S14 (자막 카드) 「해고 통보를 받은 날, 폭설」
- S15 무언: 짐 싸는 손. 명찰을 풀어 책상에 내려놓는다. 명찰 "김영곤" 클로즈업. ★

- S19 무언: 외투를 벗어 지우에게 씌우고 눈보라 속을 나란히 걷는다 (BGM 고조).
- S20 지우네 현관. 지우 엄마: "…아저씨가, 왜…" / 김씨: "…별거 아닙니다. 들어가십시오."
- S21 무언: 눈 쌓인 어깨로 돌아가는 뒷모습. 지우 엄마의 흔들리는 눈. ★

## 제작 지침 체크 (CLAUDE.md·규칙집 적용)
- 구어체 짧은 대사, 핑퐁 리듬, 리액션 컷 명시 (S6·S21·S25·S31)
- 내레이션 없음 — 자막 카드 5장 + 대화로만 배경 설명
- 무언 장면 다수 배치(2막 전체 등) = 립싱크 리스크·비용 최소화
- 화면 글자 금지: 수첩 내용은 박여사 대사로, 쪽지는 원경 흐림, 옷·소품 무지
- 한 음절 대사 없음, 감탄사·말줄임·느낌표 감정 작법
- 명찰 "김영곤": 기준 초상에 글자 없는 명찰표 착용 → 한글 폰트 합성 → image-to-video. 본편 전 시험 장면 1개 검증. 근접 뭉개지면 정지 인서트 컷 보조.
- 제작 순서: 기준 초상(캐릭터 시트) → 명찰 시험 → 목소리 오디션(사용자 청취 선정) → 대본 3종 자산 생성 → 정렬 검증 → 생성
