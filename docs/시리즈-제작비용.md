## 3. 비용을 줄인 결정 (기록용)

- 재조립은 캐시 이어하기(resume)로 립싱크·현장음·음악을 재사용해 영상 재생성 없이 반복했다.
- 끌채 변형 컷(S11·S16·S34·S37)은 재생성 대신 키프레임 정지 푸시인(무료)으로 대체했다.
- 전환·배속·앵커링·여운·자막·BGM 구간 수정은 전부 로컬 재계산 + 무과금 리믹스로 처리했다.
- S02(리액션)·S21(비)은 키프레임 정지 푸시인 + 로컬 합성(빗줄기 오버레이)으로 영상 재생성 없이 해결했다.

## 4. 다음 에피소드 입력 절차

1. 제작 시작 전 fal 잔액을 이 문서에 적는다.
2. PHASE 4·5 실행 전 보고한 예상 비용을 '추정' 칸에 적는다.
3. 완료 후 잔액을 적고 차액을 '실측'에 적는다. TTS는 ElevenLabs·Typecast 사용량 화면의 글자 수를 적는다.
