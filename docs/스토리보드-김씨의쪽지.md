# EP2 「김씨의 쪽지」 스토리보드 v1

대본 v2 기준. 규칙집 카메라 3축(Movement/Angle/Size) + 규칙 8-1(전환 연출) 적용.
컷 길이는 5/10초 블록 기준 초안 — 4단계(build_full_assets)에서 TTS 실측으로 재단.

표기: WS=와이드, MS=미디엄, MCU=미디엄클로즈업, CU=클로즈업, ECU=익스트림클로즈업,
INS=소품 인서트, POV=시점 샷. 전환: [D]=디졸브 0.5초, [여운]=리액션 0.5~1초 후 컷,
[브리지]=현장음/BGM을 컷 너머로 연결, [완충]=무언 완충 컷.

기준 초상(i2v ref): 준호방=junho-room-1, 준호복도=junho-hood-1, 준호정장=junho-suit-2,
김씨=EP1 kim-gold-1(제복·명찰 김영곤), 지우=jiwoo-spring-2, 박여사=park-spring-2.
로케이션 참고: loc-corridor-1(복도 4셀), loc-room-1(방 4셀). 계절: 초봄, 눈 없음.
