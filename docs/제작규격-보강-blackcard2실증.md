## 1. PHASE 1 길이 추정은 「발화 속도 + 비발화 시간」으로 한다 (2026-11-05 실증)

- 기획안 v1.4는 1화 완성본 밀도(2,649자 / 601.75초 = 4.40자/초)로 2화 길이를 「약 10:35」로 추정했다. 그런데 본녹음 실측 발화는 517초였다(1화 443초 대비 +17%). 1화 수준의 화면 리듬을 넣으면 본편이 약 13:03이 된다.
- **원인**: 1화 완성본은 CTA 4줄(26초)을 잘라낸 길이인데, 글자 수는 자르기 전 값이었다. 밀도가 부풀려진 상태에서 계산한 것이다.
- **규칙**: 대본 단계 추정은 화자별 실측 발화 속도(1화·2화 공통 Taniguchi 내레이션 5.2자/초, 声 5.7~6.2, 美咲 4.1~4.8, 대사 4.9~5.5, 앞뒤 무음 제거 기준)로 발화 시간을 구한다. 여기에 줄 간격(같은 화자 0.6 / 교체 0.8초), 장면 경계 1.0초, 비발화 화면(1화 실측 약 185초)을 더한다.
- **자동 검사 후보(같은 오류가 반복되면 도구로)**: 대본 생성기 마지막 줄에 「발화 추정 + 185초 > 660초면 경고」.

## 3. 측정 도구 보정 (2026-11-05)

- 1화 `04_목소리추천.md`의 측정값과 맞추려고 같은 1화 클립으로 측정 방식을 보정했다.
  - 다이내믹은 활성 구간 RMS dB의 **p95 − p50**이다(Taniguchi A 11.4 = 11.4, Jun B 8.5 ≈ 8.4).
  - F0는 자기상관 60~320 Hz, 문턱값 0.6이다.
- 숨소리가 섞인 남성 클립은 유성 비율이 35% 미만으로 나오므로 F0를 참고값으로만 쓴다.
- 도구는 세션 스크래치 `measure_voices.py`다. 다음 작품부터는 `scripts/measure_voices.py`로 옮긴다.
