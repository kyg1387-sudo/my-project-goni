# 데이터 기반 제작 운영 규격 — 일본 유튜브 상황·장르 분석을 제작에 연결 (2026-11-05 고니감독님 확정 「최상의 지침을 만들어서 활용하자」)

목적: 감으로 고치는 사후 수정을 줄이고, 기획·대본·썸네일·제목·편성·검수 모든 단계가 **실측 데이터**에서 출발하게 한다. CLAUDE.md 제21장의 상세판.

## 1. 데이터 원천(두 단계)

| 단계 | 원천 | 얻는 것 | 인증 | 저장 위치 |
|---|---|---|---|---|
| 1 | YouTube Data API v3 (공개) | 우리·경쟁 채널 영상의 조회수·좋아요·댓글 수·제목·설명·태그·썸네일·길이·업로드 시각, 댓글 전문, 키워드 검색 상위 | API 키(`YOUTUBE_API_KEY`) | 클라우드 환경 Network secrets |
| 2 | YouTube Analytics API (비공개) | 영상별 시청 지속 그래프(이탈 시각), 노출·CTR, 트래픽 소스, 시청자층·시간대, 쇼츠→본편 전환 | 채널 소유자 OAuth refresh token(`YT_OAUTH_CLIENT_ID`·`YT_OAUTH_CLIENT_SECRET`·`YT_REFRESH_TOKEN`) | GitHub Secrets |

- 키·토큰은 환경 설정과 GitHub Secrets에만 둔다(부록). 채팅·코드·문서에 쓰지 않는다. 범위는 읽기 전용(`yt-analytics.readonly`·`youtube.readonly`).
- 무료 할당량(Data API 1만 유닛/일) 안에서 하루 1회 수집. 검색(100유닛)은 키워드 10개 이내.

## 2. 수집·보고(자동)

- `scripts/yt_public_report.py`(1단계) → `docs/분석/YYYY-MM-DD-장르동향.md`·`YYYY-MM-DD-채널수치.md`·`comments/<videoId>.json`.
- `scripts/yt_analytics_report.py`(2단계) → `docs/분석/YYYY-MM-DD-유지율.md`(영상별 이탈 시각 상위 5곳을 컷 ID와 대조), `-CTR.md`, `-소스.md`.
- Actions `youtube-report.yml`: 매일 08:00 JST 실행, 결과를 브랜치에 커밋. 어느 세션에서든 `docs/분석/` 최신 파일을 읽는다.
- 장르 키워드(고정 10개): スカッと, スカッとする話, 修羅場, 感動, 泣ける, 復讐, 不倫, 介護, 相続, 嫁姑. 작품 기획 때 소재 키워드 1~2개를 임시 추가.

## 3. 단계별 활용 규칙

| 단계 | 데이터 투입 | 판정 규칙 |
|---|---|---|
| 기획 | 소재 키워드의 최근 30일 상위 20편(제목·썸네일·길이·채널 규모) | 같은 반전 구조가 상위 3편 안에 있으면 반전을 바꾸거나 소재를 바꾼다. 상위 영상 길이 중앙값 ±2분 안에 설계 |

| 검수(PHASE 6) | 직전 작품 이탈 지점 유형 | 「긴장 곡선」 검수에 이탈 유형 체크 항목을 추가 |
| 사후(공개 +7일·+30일) | 유지율·CTR·평균 시청·댓글 분류 | 작품별 성과표를 `docs/시리즈-성과.md`에 남기고, 반복 패턴은 CLAUDE.md 규칙으로 승격(지속 개선 원칙 4) |

## 10. 제작 후 관리 운영법(고니감독님 질문 2026-11-06 「영상이 많은데 효율적으로」)

- **3단계 분류**: 신작(0~7일) 매일 확인·신호 시 1개만 교체 / 성장기(8~30일) 주 1회·+7·+30일 기록 / 보관(30일+) 월 1회 2편 리프레시 + 재생목록·엔딩 화면 연결.
- **조작은 6가지, 한 번에 하나, 7일 관찰**: 제목(2단 양식)·썸네일(A/B)·설명 첫 줄·고정 댓글 링크·재생목록·엔딩 화면/카드. 변경은 `docs/분석/변경이력.md`에 행으로 남긴다.
- **손대는 신호**: 조회/일 3일 내 −50% → 썸네일 / 좋아요율 1% 미만(조회 100+) → 제목 / 쇼츠 1,000+·본편 100 미만 → 링크·고정 댓글·끝 자막 / AI·不自然 댓글 → 기록·규칙. 신호 없으면 건드리지 않는다.
- **주간 루틴(주 30분)**: 월요일 자동 보고 → 스튜디오 작업 번호대로 적용 → 세션에 「n번 적용」 회신. 월 첫 주 보관 영상 2편 리프레시.
- **지금 채널 우선순위**: ① 쇼츠 37편 고정 댓글·설명 본편 링크 ② 재생목록 2개(スカッと·美談)+전 본편 엔딩 화면을 「다음 본편」으로 ③ 5~30회 본편 6편 월 2편씩 제목·썸네일 리프레시.

## 11. 흥행 30선 선정 기준(고니감독님 확정 2026-11-06 「전문 프로로서 최대한 시청율 좋은 영상 기준으로」)

유지율·CTR은 비공개라 공개 수치로 「시청자가 끝까지 보고 반응한 영상」을 근사한다. **흥행 점수**(0~100) = 후보군 안 백분위의 가중합:

| 지표 | 가중치 | 뜻(대리하는 것) |
|---|---|---|
| 조회수 | 30% | 규모(알고리즘이 밀어 준 총량) |
| 조회/일 | 25% | 속도(공개 경과일 보정 — 신작·급상승 반영) |
| 좋아요율(좋아요/조회) | 25% | 만족도 = 끝까지 보고 눌렀는가(유지율 대리) |
| 구독자 대비 조회 배수(조회/구독자) | 20% | 구독자 밖으로 추천이 퍼졌는가(콘텐츠 힘, 채널 크기 보정) |

- 후보군: YouTube Data API `search` regionCode=JP·relevanceLanguage=ja·publishedAfter=오늘−30일·장르어, 본편은 전체·4~20분·20분+ 3회 검색 합산, 쇼츠는 4분 미만. **조회 1,000 미만 제외**. 본편(3분 초과)·쇼츠(3분 이하) 각 30편.
- 구독자 수는 순위 기준이 아니라 배수 계산에만 쓴다 → 작은 채널이 큰 조회를 낸 영상이 위로 온다(2026-11-06 실측: 구독 2,980 채널의 11:18 영상이 116만 회·391배로 スカッと 본편 5위).
- 옵션: `--sort views`(조회수만) · `--sort vpd`(조회/일만). 가중치는 `yt_genre_report.py` `SCORE_W`.
- 한계: 검색 관련도·지역 필터를 거치므로 「그 장르어로 찾았을 때」의 상위다. 2단계(Analytics)가 붙으면 우리 영상의 실제 유지율로 가중치를 보정한다.
- 갱신: 매주 월(주간 보고 안) + 매월 1일 확정판, 창은 항상 최근 30일.
