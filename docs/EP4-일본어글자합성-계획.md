## 제작 조건 (PHASE 3·4·5에 반영)
1. 위 장면은 **카메라 고정(Static, locked off)**, 소품·종이가 움직이지 않는 모션 지시만. S22는 초점 이동 → 고정으로 변경.
2. 키프레임 단계에서 **글자가 들어갈 면을 정면에 가깝게, 무지로** 생성(Kill Gate: 글자·기호 0).
3. 합성: 키프레임에서 면의 네 모서리를 찍어 원근 변형(perspective warp) → 클립 전 프레임에 같은 위치로 얹음. 종이 질감이 비치도록 곱하기(multiply) 블렌드 + 약한 노이즈·흐림으로 실사 톤 맞춤. 무과금(로컬 ffmpeg/PIL).
4. 클립에 미세 흔들림이 있으면 프레임별 위치 추적(템플릿 매칭)으로 보정, 그래도 어긋나면 정지 푸시인 폴백(손·정물 컷 허용 규정).
5. 같은 내용의 자막카드(S07 「단전 예고」, S42 「완납」)는 중복 — 제거 여부는 사용자 결정 대기(권장: 제거, 화면 글자만).
6. 한국어판은 같은 클립에 한국어 글자를 합성(영상 재생성 없음).
