### B. 우리 기획 착수 기준(하나라도 미달이면 착수하지 않음)

1. **유사 흥행 근거**: 같은 핵심 요소를 가진 3관문 통과작이 본편·쇼츠 합쳐 **2편 이상**, 그 요소의 통과율 배율 **1.2 이상**(평균보다 잘 됨). 오탐(제목만 닮은 영상)은 눈으로 뺀다.
2. **중복 금지**: 같은 반전이 소재 대조 상위 3편·우리 작품에 없다(최우선 원칙 7②).
3. **이탈 설계**: 0~5초 질문, 30~40초마다 열린 고리(10~11분에 14개 이상), 논리 검수표 3문항 차단, 구간별 예상 이탈 표.
4. **AI 티 위험 「상」**(동물·군중·불꽃)은 쇼츠로 먼저 시험해 기준 C의 쇼츠 선을 넘긴 뒤 본편.

### E. 통과작에서 가져와 적용할 것(유사 흥행 스토리 → 우리 안)

1. **「건네받은 물건 + 숨은 숫자」**(離婚当日 카드 「暗証番号0427」, 통장 잔고, 결혼반지 → 質屋) — 3번 이혼서에 「이혼서 날짜의 숫자」를 반전 열쇠로: 20년 전 날짜 = 빚을 진 날, 마지막 상환일 = 같은 날짜. 제목에 숫자를 넣는다.
2. **「優しい嘘(다정한 거짓말)」 어휘** — 통과 쇼츠 2편 합계 828만. 3번 쇼츠 ③ 제목을 「夫の、二十年の優しい嘘」로, 4번 재구성 제목을 「姑の優しい嘘」로.
3. **「〇〇がとった行動とは？」형 쇼츠 제목**(476만·173만) — 6번 쇼츠 ①을 「優先席を譲らない老婦人が、次の駅でとった行動とは？」로.
4. **본편 제목에서 「毎晩·毎朝」「最後の」를 앞에 두지 않는다** — 본편 통과작 중 「매일 반복」 0/150, 「기한·마지막」 0/184(쇼츠에서는 1.22·1.96배로 강함). → 반복·기한 단어는 **쇼츠 제목**에, 본편 제목 앞 30자는 「관계 + 물건 + 결과」.
5. **길이**: 본편 통과작 길이 중앙값 63분(사분위 19~144분), 8~15분은 17/91편(19%). → 과감한 제안 3(15분 판)·합본(제22장 2)의 근거가 더 강해졌다.

- **구간 요약**: 0:00 「たった一発のために、百万円ですか」 → 1:00 허가 서류·안전 규정 대립 → 2:00 유사쿠의 작업장, 이름 없는 한 발 → 3:00 마을 노인들이 다쿠마를 피함 → **3:30** 「その一発には、名前がなかった。三十年前から、ずっと」 → 4:00~6:30 다쿠마가 항구 기록·어머니에게 묻기 → **7:00** 아버지 유품 항해 일지 「二十時十五分 花火見ゆ 帰港」 → 7:40 다쿠마가 소방 입회로 허가를 직접 받아 옴 → 8:30 20:15, 한 발(정점: 정적 → 폭발음 −9) 「航、帰ってこい」 → 9:20 다쿠마 「来年も、上げます。役場の予算で」.
- **논리 검수**: ① 아버지는 왜 말하지 않았나 → 위 대사 ② 왜 20:15 → 무전 기록 ③ 안전 허가 → 다쿠마가 소방 입회 조건으로 해결(직업적 성장).
- **제목**: 【感動する話】「たった一発のために、百万円ですか」花火大会を廃止した若手職員。老花火師が三十年、八時十五分に一発だけ上げ続けた理由を知り、彼は――
- **결과어** 「八時十五分」. **쇼츠**: ①「たった一発のために、百万円？」 ②「その花火には、名前がなかった」 ③「親父、花火が見える――最後の無線」 ④「八時十五分、一発だけ」
- **약점**: 밤바다·불꽃 i2v 결함(형태 변형) → 불꽃은 원경 정지 + 로컬 합성 광원 / 회상 폭풍 장면 비용 → 무전기·파도 소리 + 손 인서트로 / 공개 시기(11월)와 여름 소재 불일치 → 「最後の花火大会は秋祭り」로 설정 변경 가능.
