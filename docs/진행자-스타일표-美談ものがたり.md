# 美談ものがたり 아웃트로 진행자 스타일표 (2026-10-14 고니감독님 지시)

> 「아웃트로에 나오는 예쁜 아가씨는 영상 제작마다 동일하면 안 될 것 같다 — 헤어스타일과 옷을 다르게, 예쁘게.」
> 원칙: **얼굴은 채널 공식 진행자 그대로**(`assets/portraits/ashita-host-1/host-cu-4.png`, 목소리 Yui Sato) — 시청자가 「같은 진행자」로 알아보게.
> **머리 모양·옷·작은 장신구만 작품마다 바꾼다.** 같은 스타일을 두 작품 연달아 쓰지 않고, 화(スカッと)·금(美談) 분위기와 계절에 맞춘다.
> 방법: 작품마다 `scripts/portraits/<작품>-host-1.json`(가슴 위 후보 2~3종, 얼굴 참조 host-cu-4) → 선택 → `<작품>-host-2.json`(같은 스타일 허리 위·손 흔들기) → 립싱크 4컷(OUT1~OUT4, 녹음은 재사용). 비용 약 4달러(이미지 약 0.3 + 립싱크 약 3.7).

## 진행자 스타일 라이브러리 (2026-10-14 고니감독님 지시)

> 「아웃트로 이미지는 전체 저장했다가 다음 영상에 적용하면 될 것 같아」
> **`assets/host-library/`** 에 스타일별 가슴 위(cu)·허리 위(wu)·손 흔들기(wave)와 미채택 후보(_unused)를 모두 보관, 목록 `assets/host-library/index.json`.
> 새 작품은 ① 라이브러리에서 직전 작품과 다른 스타일 선택 → ② 빠진 컷만 생성 → ③ 범용 립싱크(OUT1 구독·OUT3 장르 공통 예고·OUT4 인사)는 같은 장르·같은 스타일이면 재사용, 작품별 멘트만 새로. 절감: 이미지 약 0.3달러 + 범용 립싱크 약 2.7달러/편.
